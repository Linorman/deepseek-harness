# Agent Note: World 创作键盘控件

Status: implemented

[English](2026-10-15-world-authoring-keyboard-controls.md) | 中文

## 问题

定义表格需要支持键盘编辑，不能仅因打开编辑器就改变已保留的值。闭合选项和草稿引用需要一致的选择与焦点行为。滚动表格内的弹层可能被裁切，源码缩进也必须保留可访问的键盘退出路径。

## 决策

功能内的 [ReferencePicker](../../../../packages/client/ui-simulation/src/client/WorldReferencePicker.tsx)同时拥有已声明引用建议和表格闭合选项。初始高亮当前值，即使它位于普通 50 项建议前缀之外。方向键改变 active descendant；Enter 提交，Tab 提交并在网格中移动，Escape 取消并恢复单元格焦点。闭合选项不提交未匹配文本，失焦取消本次编辑。源码草稿中既有的未声明值保留到显式修正，不静默擦除。

列表通过 portal 进入最近的已打开 dialog 或 document body。共享定位 hook 测量并限制其位置，跟踪滚动与 resize，避开表格裁切。输入保留焦点及其 listbox 关联。活动选项只滚动列表内部，不滚动页面。

表单 textarea 大小遵循明确行数，源码编辑器遵循所属面板；内容在其边界内滚动。源码面板提供可见焦点框与快捷键说明：Tab 缩进，Esc 后 Tab 退出，Ctrl/Cmd+Enter 检查，F8/Shift+F8 在诊断间移动。

表格操作列使用完整本地化列标题，不再使用空行号标签。预览键值列共享可用宽度，让长键名换行，同时保持每个数字额度单行可读。浏览器检查覆盖两种持久后端、浅深主题及桌面/窄屏。

## 考虑过的替代方案

原生 select 为表格单元格引入另一套交互，无法共享引用查找行为。无界建议列表增加工作量并模糊覆盖范围。在表格内提高 z-index 不能解决裁切。

## 后果

这些控件只改变草稿展示与编辑，不查询权威业务状态、不推理、不创建运行或提交管理命令。组件测试负责原值保留与焦点行为；真实浏览器证据负责弹层几何、键盘退出、主题、窄屏及减少动效。[DESIGN.md](../../../../DESIGN.md) 与 [UX-CONTRACT.md](../../../../UX-CONTRACT.md)保留产品层规则。
