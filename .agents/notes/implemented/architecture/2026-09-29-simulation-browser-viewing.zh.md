# Agent Note: 独立 Simulation 浏览器查看

Status: implemented

[English](2026-09-29-simulation-browser-viewing.md) | 中文

## Problem

Simulation 元数据 API 需要独立浏览器入口，不能伪装为 Team 工作区，也不能启动执行。浏览器断线、授权替换和晚到响应必须按实际含义保留或清理内容。业务状态不能迁入 React 查看 store。

## Decision

显式启用的 [Simulation UI](../../../../packages/client/ui-simulation/README.zh.md) 贡献导航入口和 layout 所有的 `simulation.workspace` slot。Host 入口要求产品目录，未组装时不公布导航。共享 layout 查看状态通过 `showWorkspace()` 选择 Team 或 Simulation，并保留现有 Team/Session 子树。产品选择写入 URL，不可用的 Simulation 深链保留返回操作。

只读 Team 选择不要求已有绑定 coordinator。无 coordinator 的 Simulation Team 可检查获准模块及精确成员 Session，不虚构协调会话。明确 Team open／start／resume 仍要求 coordinator 返回值；绑定前不显示协调会话操作。目标恢复先清除旧 Session 检查器再校验，因此精确引用被拒绝时错误及恢复入口仍可访问。

跨产品检查使用共享布局导航服务及精确 Team 查看 URL。它追加历史而不重载保留草稿，前进／后退恢复产品可见性，同文档跳转通知路由所有者。Team URL 键由单一位置持有；读取链接移除继承的修改表单。目标负责认证、对象归属及精确参与者／Session 校验。历史 Session 引用不跳到替换绑定，未落盘引用保持静态。产品登记所有权不授予 Team 访问权限。Simulation 来源和对象面板共用语义化读取链接控件。

Client runtime 拥有 `simulationRuns`，目录/run/集合/对象/模板/控制各只保留一个响应页。每次请求具有取消生命周期和捕获的授权代际。启动 watch 时，待决对象读取在触发 abort 回调前先发布停止加载且已过期的状态；已保留的上下文或知识正文被移除，已完成的公开详情在更新的观察将其标记过期前仍可阅读。已取消的晚到响应不能重新发布内容。握手完成才允许读取；账号替换与明确拒绝清理业务内容，普通网络失败保留标记过期的页面。查看 store 保留导航、已提交搜索、滚动位置及有界创建原始输入；业务 receipt 和不可变已提交请求仍由 runtime 持有。UI hook 通过现有框架 inject 绑定，组件不接收 Context 或服务对象。

已提交集合状态／认知筛选、关联实体／决策 ID 及操作分区保存在仅查看的 URL 状态中。执行有界 Host 查询前移除不适用选择。发布尝试与检查点来源独立于集合分页；续页固定观察 revision，首页刷新清除此约束。读取失败保留内容并禁用续页。切换运行先退休查看检查器与恢复来源请求，再清理其响应。

已退休 Simulation actor 可以保留无文件系统 cwd 的 Team 绑定 Session 日志。产品列表及冷历史／媒体检查仅在当前 Team 读取与精确成员／Session 校验通过后接受该持久归属。只读来源检查比对返回 header 身份及祖先关系，并在 IO 后复查授权；普通无位置根日志及通用 Agent 恢复仍受原限制。不创建 Agent 或运行所有者。

Team 选择与目录摘要仅公开从不可变原生规则派生的 `simulation-managed` 执行标记，不公开运行身份。浏览器移除这些 Team 的普通生命周期、修改、发送及回答操作；绑定 Session 检查不呈现输入／队列／审批控件，仍保留输入所有者及草稿。Hub 与 Host 独立拒绝普通人工写入并返回明确策略拒绝，包括绕过 UI 提示的调用者。Simulation 专用 proof 所有者保留原操作。读取权限独立，不由运行所有权授予。

页面使用共享控件和工作区 token。模拟时间与 ID 保留字符串。保存的 running 调度、观察到的所有权、已接受决策、已执行效果、发布及接收方事实各有独立含义。对象详情为非模态，窄屏只提供一个主要区域和可见返回操作。导航和读取均不包含执行命令。

原命令所有权独立于导航和传输等待者。UI 注册插件创建有界 runtime owner，捕获编写输入时的授权版本，在 IO 前保留完整原输入，只查询或重试该身份。数量及完整 UTF-8 字节限制在拒绝时保留旧记录。未知或进行中原操作不能释放；`not-found` 既不证明失败，也不允许自动替换。账号退役在后到响应发布前清除私有原记录与草稿；普通断线保留。创建使用已安装模板，将后来原始编辑与已提交请求分开，保护重载和输入放弃。有效传输缺少行政权限，不代表独立获准查看权限失效。

场景任务审核拥有独立的概览页面和表单，普通 Team 修改入口保持关闭。Host 只暴露固定库存转移／报告发布核验事实以及准确的操作／尝试／审核实体／版本元数据。Runtime 保留一个可取消页面，审核读取拒绝与元数据查看分别处理，并在接受查询结果前核对恢复的原选择和规范原因。私有草稿按运行／操作／尝试隔离，受共享输入条目数与 UTF-8 额度约束。关闭或断线保留输入，授权替换清理；未知命令只能查询／重试原 payload，命令规范化原因空白并保留原始提交草稿，完成结果只清理完全未修改的原始输入，后来仅修改空白也保留。终态失败须改写语义或明确核对新版本才能另建命令；审核写拒绝保留作者输入与独立查看，真实认证退役仍清理。明确的版本确认仅更新同一尝试，不能让替换尝试隐式继承旧审核。审核原操作不进入维护表单。[原生审核权限](2026-10-01-simulation-task-review-authority.zh.md)拥有休眠审核实体准入和持久重试归属。

目录状态拥有独立的准确有序 ID 读取族，只能查询当前有界名称页。名称与运行观察分别结算，名称替换退休旧状态 IO，普通失败保留可见的过期状态，明确拒绝清理受保护元数据。原生批次与行政补充提供安全的当前时钟／版本／用量、调度停止与场景事实，不打开 writer，也不公布动作授权。未知或失败观察不能变成零，场景身份不从显示名称得出。所有模块共用持久状态／控制页头，紧凑维护入口打开同一保留表单。原生预算占用包含预留和未结算推理；按真实时间观察的 Host 全局模型 permit 与队列占用另行展示。

目录选择在状态发布与退休回调前预留自身 ordinal。订阅或 abort 监听器重入选择另一目录／运行时，旧流程在 IO 前失效；响应只接受原 ordinal 和代际。Simulation 目录、概览与请求记录随工作区滚动；集合表及非模态详情拥有各自阅读区域。自然高度的页头与模块导航位于集合滚动区域之外。滚动归属随保留的目录／集合查看上下文移动，对话框滚动仍归自身持有。

外部重试许可与目标对账分别持有。有界的结果未知操作预览只定位准确元数据，不扫描原生历史。表单保留当前原尝试次数与 Host 允许性；不可变规范命令归 runtime，后来原始原因归共享额度的查看 store。原查询核对每个选择与规范原因。完成授权只登记许可，目标重试需要明确调度；修改意图不能覆盖不确定原命令，终态拒绝须改写语义或明确核对当前次数。结构化检查点／恢复诊断只展示固定阶段／类别及准确的运行／实体／检查点／Team／频道／Session 对象；完整归属引用经过既有读取 owner 定位。私有错误只归 backend，清理未知不能被视为静止证明。

控制轮询观察产品调度器，不打开 writer。Host 提示及不可变预算／模型额度决定开始确认，原生写入重新检查准入。后台刷新保留有效旧控件。未知原意图阻止相同新意图。暂停与在途清理保持独立观察。原生 revision 自动触发可见元数据与 World 窗口重读；调度生命周期变化也会刷新运行及任务／请求摘要。视图等待在途读取完成并合并后续变化，保留选择与草稿，不携带旧续页游标重新读取绑定修订的列表。后台刷新保持已有内容和空状态的视觉稳定，不播放加载动画、不使内容变暗，也不插入过期提示；待决和过期标记仍用于读取／命令校验。心跳时间戳与更新的 watch 游标不算数据变化；隐藏或断线时停止自动读取。日志原文与来源分页仍由各自 owner 管理。

网关 Service facade 转发完整 Simulation 命名空间。浏览器配置通过 modules 插件的 `browserConfig` 明确提供，Host 插件配置不隐式成为浏览器配置。

[Team 工作台决策](2026-09-11-team-workspace-ui.zh.md) 继续约束自身业务。[产品目录决策](2026-09-29-simulation-product-directory.zh.md) 保留持久化、权限、投影和元数据限制；此记录负责浏览器组装。两者均未被完全取代。


[工作区层级决策](2026-10-01-webui-workspace-hierarchy.zh.md)拥有呈现层级、来源返回反馈与请求对账。本记录保留独立的组合、授权及生命周期契约。

## Alternatives considered

**将 Simulation 作为 Team 标签。** Team 控制语义不拥有仿真调度、准备或跨所有者恢复。

**将 API 响应保存在 UI store。** 这会重复业务所有者，使组件生命周期影响权限与请求取消。

**仅取消待决对象读取而不发布退休状态。** 已取消的响应无法完成旧请求，导致 `loading: true` 永久保留，详情刷新操作持续禁用。

**从浏览器页面打开原生 run。** 这会把浏览变成执行所有权，并与已持有的协调器冲突。

日志元数据与原文由 runtime 分别持有窗口。插件所有的记录导出器在 React 外保留有界临时文本，核对同一 revision 下跨页的连续原文分片与总数，并在同步交付文件前重新检查策略。取消、授权／选择变化及读取失败均清除缓冲，已完成下载的文件由用户持有。浏览器额度限制完整 UTF-8 输出与分页工作量。

来源查看状态只保存决策中的序号，原文页及依赖 Team 的权限归 runtime 持有。有界读取结算后轮询覆盖独立 Team 成员资格变化；已知撤权帧立即退休唯一来源页，包含规范父团队依赖。策略和连接退休拒绝旧响应，普通网络中断明确标记过期。来源续页绑定冻结决策与精确原文身份，不绑定不断推进的世界尾部，因此活动运行不会反复重置历史正文。

创建只接受 Host 声明的可编辑额度，并在有界内存中保留原始覆盖值。Runtime 预检不分配命令，显示固定的 Host 共享并发上限；实际创建在分配原命令前重复检查。编辑草稿、关闭、暂停查看、连接及授权替换退休旧校验，因此晚到成功不能创建运行。字段拒绝保留输入并聚焦首个错误。Tick 上限保留十进制字符串，容量和 token 整数控件拒绝非安全 Number。

“更多”中的请求记录在重新认证后读取仅含 receipt 的行政历史，独立于已清除的私有输入。游标／revision 属于命令日志，Native 世界推进不使其失效。冷原选择仅保留 runId／commandId；明确重试调用 Host 保存的原语义 payload，终态 receipt 不再次执行。已有命令保留原 payload 类别。元数据查询不恢复工作，冷审核／授权仍须明确恢复 owner。导航退休旧响应及刷新回调，已受理 Host 工作继续保留。

任务取消保留独立 run／operation 草稿与必填可空 attempt fence。有界任务窗口归属 Runtime，原始 reason 共享既有草稿额度。原选择器只重开取消表单；未知结果查询／重试不可变原命令。Native 在物理排空前持久化取消，晚到工作被拒绝，而清理责任保持可见。取消后再次读取 Team 规范任务，由 Native 校验精确 attempt 证据并拒绝矛盾观察。既有世界效果保留。

## Consequences

已安装行政组装提供创建、显式调度、检查点、恢复和实体输入。冻结上下文、知识、来源原文及日志导出分别受独立授权约束；元数据引用不授予 Team／Session 正文访问权限。完整语言／主题／可访问性／恢复矩阵及新增审核自动场景仍在[实施计划](../../../../design/webui-team-simulation-2026-09-28/implementation-plan.md)中独立跟踪。

## Verification

Runtime 测试覆盖查询替换、晚到响应、离开视图、断线、授权替换、过期页及拒绝。Layout/Team/sidebar 回归保留现有导航。真实 Loader/Host 浏览器场景使用持有的原生 run，读取有界登记/实体页，重载对象深链，检查桌面/窄屏、控制台健康、phase/revision 不变和无模型流程。这些证据不代表创建、检查点、恢复或自动执行完成。

[行政浏览器场景](../../../../apps/web/tests/simulation-administration.snapshot.ts)通过真实 JSON／SQLite Loader、HTTP／WebSocket、原生 actor／工具和库存路径验证，仅将外部推理脚本化。覆盖创建响应丢失与同原请求重试、暂停创建／重载不推理、预算确认、在途暂停、明确继续、当前库存、原生三工具请求、凭据替换与草稿清理。浏览器 snapshot 固定作用域 persona 输出。聚焦的 Runtime 命令／读取测试覆盖取消、过期编写上下文、完整字节拒绝和账号退役。这些证据不代表 Web 维护或自动任务执行。

[元数据浏览器场景](../../../../apps/web/tests/simulation-workspace.snapshot.ts)验证已提交状态／认知筛选、成功空结果、URL 重载、关联实体范围及浏览器后退。[维护浏览器场景](../../../../apps/web/tests/simulation-maintenance.snapshot.ts)读取 JSON／SQLite 生产发布尝试，读取响应丢失后保留内容，沿决策／操作跳转并分页完整检查点来源，世界状态与推理次数不变。它还让已授权上下文响应跨越策略 watch 换代，验证加载结束、刷新恢复可用且旧正文不重现；聚焦 runtime 测试覆盖 watch 启动时取消待决对象读取。组件用例覆盖两种语言及续页拒绝；runtime 回归验证切换运行退休未完成恢复来源响应。这些检查不代表私有正文读取、事件导出或完整验收矩阵完成。

日志浏览器场景以原生记录核对 JSON／SQLite 元数据与原文下载，验证取消不生成文件、失败分页保留、来源序号重载、策略撤销及窄屏原文续页。Runtime 验证覆盖字节／页数额度、不完整／重复分片、最终复核、旧响应和授权／选择退休；这些检查不代表剩余完整语言／主题／键盘矩阵已完成。

[外部操作重试浏览器场景](../../../../apps/web/tests/simulation-operation-retry.snapshot.ts)验证 JSON／SQLite 生产目标先持久化后丢失响应，原额度耗尽。授权、原查询和精确重试不改变 phase 或模型调度；明确调度后返回同一 Envelope ID，目标 WAL 仅有一条记录。原 sender 决策／inference 和全部关联该决策的 token reservation 保持不变；每个模型尝试核对持久 Session 上下文 input ID 及重建请求 header 的 route。三个工具轮次是一个决策中的独立模型尝试，不是三次重播决策。成功检查点之后，真实准确 Session 读取失败只产生结构化采集／来源不可用诊断，含准确 Session／Team 绑定、不展示私有错误字符串，行政服务冷重载后的原查询保持同一诊断。
