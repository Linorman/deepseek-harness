# Agent Note：持久化频道摘要

状态：已实现

[English](2026-09-01-durable-channel-summaries.md) | 中文

## 问题

摘要影响模型可见的频道历史。读取时截断文本无法证明代表哪些已接纳消息、保留稳定重试结果，也无法防止私密子集消息进入全局可见摘要。因此生成需要显式授权命令和持久化来源关系。

## 决策

`clocky-team` 定义选择、来源读取和摘要提交方法。`clocky-team-channel-summary` 是已组合的确定性抽取 Consumer：通过 Hub 读取有界来源，在 Hub 队列外抽取，保留选定的 adapter 与 view-policy 实现，并签发短期规范输出证明。当前协调者工具和经过认证的人类 Host API 调用该 Consumer。独立请求者证明绑定当前协调者 activation，或人类的精确 `send` 输入；仅有系统输出证明不授予调用者权限。

新命令要求 Team/频道活跃、没有关闭或取消意图、显式频道策略获准，并使用精确频道游标。每条选定消息必须对所有不可变 manifest 成员可见；发送者可见性及已接纳 Envelope 的 audience 建立该关系。私密子集来源在生成前拒绝，不暴露隐藏文本。全频道记录格式没有按查看者区分的可见性掩码。

持久化记录保存来源 WAL 范围、精确有序 Envelope id、完整来源值的规范 SHA-256 指纹、文本、策略身份和频道作用域幂等键。Hub 重读该范围，在追加前检查身份、可见性、指纹和权限。WAL/checkpoint 恢复验证相同来源关系。摘要来源证明阻止压缩删除来源范围。频道 WAL 版本 6 和 checkpoint 版本 9 要求指纹，拒绝旧格式。

匹配的键/范围重试返回原摘要，即使游标过旧或已经重启。冲突范围或底层负载复用会被拒绝。新身份需要新游标。`summarized-window` 策略投影最新持久化摘要和未覆盖的有序原始尾部；没有摘要时投影原始消息。默认 TeamRun directed 频道支持返回摘要文本的显式命令，同时保留原 directed 投影，不会自动缩短模型历史。

## 考虑过的替代方案

**读取时生成或本地缓存。** 两者都不能建立持久化来源或稳定的重启幂等性。视图只投影已接纳事实。

**把摘要当作普通成员消息。** 这会排队产生收件人工作，并赋予生成的控制文本会话输入身份。独立记录保持投递与回执状态不变。

**无界或隐式模型摘要器。** 已组合 Consumer 使用可配置的历史、来源字节、来源数量和输出字节上限。文本抽取不需要模型调用或合成 usage。未来模型实现必须拥有 Team Task，并通过真实 Session 记录请求。

**把私密文本放入全局可读摘要。** 按查看者投影无法撤销已持久化在全频道文本中的泄露。这类范围会被拒绝；私密摘要需要独立的持久化可见性设计。

## 结果

显式工具和人类 API 返回可用文本及持久化重试身份。JSON/SQLite Loader 快照经过真实默认协调者、工具执行器、人类绑定器、Host fetch carrier、Hub 和 AgentClient，并独立重读存储指纹，从持久化 Session 事件重建摘要加尾部投递。provider 回归覆盖可见性、旧游标、有界 Unicode 抽取、证明撤销和畸形持久化来源。

抽取处理文本负载和仅含文本的内容数组，不调度自动压缩、不总结图片、不推断事实，也不生成模型请求。保留来源占用存储。模型生成摘要、属性/模型测试、浏览器/GIF 与负载证据不属于本实现。
