# Agent Note: Simulation 检查点公开失败引用

状态：已实现

[English](2026-10-01-simulation-checkpoint-failure-diagnostics.md) | 中文

## 问题

泛化的检查点／恢复失败无法指明需要处理的保留所有者。原生 provider 错误可能包含私有文件路径或消息；将其正文解释为公开类别会泄漏数据，并在 provider 改变措辞时改变语义。主验证失败和清理未确认可以同时存在。

## 决策

[原生诊断](../../../../packages/simulation/simulation/src/checkpoint-diagnostics.ts)定义固定阶段／类别和一个规范对象。纯类型与解析器入口不包含 Cordis 服务。规则检查在实际检查处给出类别；[跨所有者 IO 辅助函数](../../../../packages/simulation/simulation-team/src/checkpoint-failure.ts)将未知读取归到调用方选择的所有者，并识别带类型的游标／来源移动。收集／恢复保留已有的有界移动重试。Session 对象使用运行的规范绑定，包括持久 header 字段可选或不一致时。

失败的原生检查点独立保留私有错误文本和可选的安全元数据，不改最近成功 manifest。JSON／SQLite 重放及精确终态重复请求保留原诊断。恢复清理失败通过 AggregateError 子类保留两项私有原错误，并独立标记清理未确认；任一错误都不能授权执行。

[产品命令日志](../../../../packages/simulation/simulation-product/src/creation-book.ts)只为失败的检查点／恢复请求保留安全元数据。终态折叠在发布前验证完整回执类别。原生检查点详情和原请求查询返回已记录诊断，不包含 provider 正文、路径或载荷。公开解析器拒绝多余属性，以及成功或无关请求类别上的诊断。命令查询、冷读取及诊断导航不取得执行所有权、不推理、不回滚或修复来源；关联 Team／Session 正文仍须独立鉴权。

World 准备保留原失败初始 checkpoint 和创建回执。明确的新准备命令从自身派生独立 checkpoint 身份，复用原采集策略，并对账同一冻结拓扑和生命周期 owner。受信 helper 只准入来自已受理准备尝试的精确 checkpoint；更改策略、复用失败身份或在原失败前提交尝试均在变更前拒绝。

## 备选方案

**解析 provider 消息。** 私有路径可能泄漏，相同措辞也不能证明失败规则相同。

**隐藏全部来源信息。** 操作人员无法区分 Session 不可用、检查点实现不匹配或所有者冲突。

**用清理失败替换主错误。** 会丢掉恢复被拒绝的独立原因。

## 影响

精确规范身份可作为导航目标，但不授予正文权限。未知失败使用不可用类别；缺少元数据时不能猜测原因。来源修复后安全诊断仍属于历史事实。明确的新检查点／恢复请求重新验证当前事实，不能覆盖原失败结果。

## 验证

原生和跨所有者测试验证 JSON／SQLite 重放后的诊断保留、私有多余字段拒绝、验证／清理错误同时保留及来源移动重试。产品测试注入真实 Session 引用读取失败，验证精确来源在终态日志重载后保留、成功锚点不变，且原查询不打开运行或请求模型。传输与浏览器测试由各自读取方负责。
