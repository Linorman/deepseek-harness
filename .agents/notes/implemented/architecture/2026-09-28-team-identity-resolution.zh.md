# Agent Note：授权身份引用与缓存生命周期

状态：已实施

[English](2026-09-28-team-identity-resolution.md) | 中文

## 问题

任务负责人或频道参与者可能不在当前成员页。为了名称抓取所有成员会破坏有界视图；主体变化后保留旧授权下的名称会暴露其他认证上下文的数据。

## 决策

规范父团队检查由[父团队检查决策](2026-09-28-parent-team-product-inspection.zh.md)管理。它扩展当前人工读取 proof 可锚定的归属位置，同时保留本决策的缓存、主体代际与撤销规则。

`resolveIdentities()` 要求绑定请求内容的活跃人工成员读取证明。Hub 对请求 ID 去重，在串行器内直接查找成员，只返回显示名称前缀和参与阶段。未知 ID 返回不可用条目。分页保留请求顺序，以 Team 版本约束续页，复用行数、文本及完整页面字节限制；查询不会枚举成员集合或启动 actor。

Host 为 `team.identity.resolve` 和 `host.describe` 添加不透明的主体代际标识。该标识对主体 ID、issuer、subject 和凭据代际求哈希，是缓存元数据，不是权限。身份与成员详情 handler 在读取后复查权限。成员检查为精确的引用成员保留证明，在元数据读取前后验证当前人工成员身份。完成的连接握手固定客户端上下文；身份响应不能改变它，已取消 watcher 的响应不能发布。

Runtime 为每个连接拥有一个有界身份缓存。在固定授权上下文内，键包含 Team 和成员。可见引用去重后分批读取，所有页的版本与认证必须一致才发布。缓存淘汰最早保留的条目。切换视图停止轮询并保留同一上下文的名称；断线保留名称并标记不可用。授权拒绝或上下文替换会取消读取，清除名称及其他 Team 详情投影。Team 列表与启动响应发布前也检查授权代际。

浏览器凭据成功替换时，撤销该 bootstrap 请求携带的旧会话 cookie。撤销先中止旧调用与流，再安装新会话。失败的 bootstrap 不影响当前会话。随后通过握手比较，在刷新新连接前清除旧主体投影。

任务负责人、尝试和频道参与者使用同一个 runtime 身份观测。名称缺失不改变已分配事实。离开成员保留历史名称与离开标记；身份不可用时隐藏过期名称。任务负责人、尝试历史、概览和频道详情通过共享成员引用控件打开授权检查器。检查器提供完整 ID，仅在剪贴板接受写入后报告成功。名称尚未重新验证时显示断线状态。UI 不拥有名称缓存，也不遍历成员。轮询周期、请求批大小与保留容量均为经过验证的浏览器部署配置。

## 考虑过的替代方案

**在 React 缓存当前成员页。** 当前页不覆盖全部引用身份，视图组件也不能拥有认证失效处理。

**接受最后到达的身份响应携带的上下文。** 响应顺序不能证明当前主体，旧请求可能在凭据替换后才返回。握手固定权限上下文，请求代际拒绝过期工作。

**网络一中断就清除名称。** 传输中断本身不能证明授权变化。同一上下文中的名称在明确标记不可用时仍有价值；上下文变化或读取拒绝才清除它们。

## 影响

身份读取独立于成员分页，不改变任务所有权。[产品提案](../../proposed/architecture/2026-09-28-web-team-simulation-product-integration.zh.md) 继续拥有 Team 待处理事项、任务草稿与 Simulation 产品接入。不透明标识只协调进程内缓存，不是持久身份格式，也不是可独立部署的认证协议。

## 验证

纯投影测试覆盖直接查找、Unicode 前缀、请求去重、续页和字节限制。JSON 与 SQLite 测试验证授权读取不写日志。Host 测试覆盖外部主体、凭据变化和读取中撤销。客户端测试覆盖有界淘汰、不一致分页、网络失败、上下文变化、迟到响应与详情清理。真实浏览器场景将已完成任务的负责人翻出当前成员窗口后，任务仍显示正确名称。
