# Agent Note: Team 与 Simulation 工作区层级

Status: implemented

[English](2026-10-01-webui-workspace-hierarchy.md) | 中文

## Problem

持久的 Team 与 Simulation 能力需要清楚的操作工作区。拥挤的页头和技术字段会遮蔽下一步操作；保留草稿可能让失败目标看起来像较早的对象；本地已受理回执可能与已完成请求元数据冲突。呈现必须消除这些歧义，同时保留执行与授权语义。

## Decision

沿用 Cordis slots、framework-bound hooks、runtime services 与语义 token。Team 和已安装的 Simulation 是并列工作区入口。领域选择、筛选、滚动位置和有界私有草稿保留原有 owner；组件不保存第二份业务响应缓存。

工作区根节点填满内容区。身份、主操作、状态与导航分别占据空间；人类待办与待执行任务保持不同含义。Simulation 集合共享筛选、分页和详情几何，但保留领域自己的列。精确模拟时间保持字符串，业务结果、发布和送达各自呈现。行数据来自已有有界摘要，不逐行读取完整对象。

目录、概览和请求记录随工作区滚动；集合与非模态详情拥有各自阅读区域，窄屏只保留一个主面板。宽表单保持操作位置稳定；视口高度不超过 420px 时整张对话框滚动，避免固定标题和页脚占满字段区域。原生模态层负责焦点隔离，包括位于 Session 检查之上的图片预览。首次工作编辑器是内联区域。可写协调者沟通与只读执行记录共享稳定的会话子树；关闭查看不取消执行。

请求目标、已显示对象与来源路由分别处理。拒绝、缺失、绑定失效和读取失败具有自己的目标主体。来源历史只保留有界同文档视图参数，不保留私有输入。返回时重新校验来源并恢复仍存在的控件或标题焦点；隐藏视图不能消耗焦点标记。旧选择在 Team 启动 IO 前清除，迟到的接纳响应不能关闭随后主动打开的检查视图。

Runtime 在匹配的运行及请求日志 revision 范围内，比较保留回执与独立观察的请求元数据。元数据不能合成回执，也不能授权替换命令。已知终态和冲突只允许查询。预留容量标记报告无法容纳的观察，保留原输入与查询能力，在新鲜元数据可容纳前阻止重试／释放。分页外缺失不代表失败，也不能清除此标记。

请求记录是“更多”中的次级目的地，与世界事件“记录”分开。持久页与已有原命令只呈现一次；分页外原操作及管理／输入身份仍可恢复。Workspace 统一拥有进入概览和请求记录时的请求读取，隐藏请求记录呈现不会移除对账。尚无运行身份的未知创建仍可从目录恢复。 查看保留的维护原操作时，先选择其准确运行，再打开使用原 command key 的对话框；查看不会分配替换请求或重复执行。

自动任务能力来自保留创建 driver 所投影的不可变执行模式。已确认仅认知执行的运行省略自动任务控制；零数量或读取不可用不能证明能力不存在。已知原生记录类型具有本地化标签，精确自定义筛选以及未知或截断类型字符串保留原义。

[Team 工作区决策](2026-09-11-team-workspace-ui.zh.md)保留 Team 组合、产物及变更权限边界；[Simulation 查看决策](2026-09-29-simulation-browser-viewing.zh.md)保留读取族、私有正文权限、持久身份及恢复语义。两者均未被完全取代。[DESIGN](../../../../DESIGN.md) 与 [UX-CONTRACT](../../../../UX-CONTRACT.md)拥有当前呈现约定。

## Alternatives considered

**仅做外观调整。** 颜色和间距不能解决目标身份或同一请求的观察冲突。

**重写前端及状态管理。** 既有取消、授权、草稿保留及命令恢复已经表达所需业务边界。替换它们增加回归风险，却不能改善这些边界。

**统一成一种管理表格。** 实体、决策、操作和检查点回答不同问题。共享几何不能成为抹平语义或逐行获取完整对象的理由。

## Consequences

渐进披露减少初始阅读负担，详情与恢复则需要明确导航。共享布局影响所有消费者，因此视口几何、键盘焦点、迟到回调与授权退休需要组装浏览器证据。原生模态预览避免 body portal 内容被另一对话框挡住。

[实施计划](../../../../design/webui-review-2026-10-01/implementation-plan.md)与[验证记录](../../../../design/webui-review-2026-10-01/evidence/implementation/verification.json)注明覆盖范围及限制。真实 Host 测试使用隔离 JSON／SQLite 存储，需要执行时使用脚本化推理。覆盖原请求恢复、来源撤权、精确绑定、双语主题、原生缩放、键盘行为及草稿保留。20／200 实体对照约束 DOM 与请求数量，不构成生产负载或跨设备延迟保证。Keyless 证据不替代 GUI PR 的真实 provider 录制。

原生缩放证据通过浏览器 context 拥有的扩展文档调用 `chrome.tabs.setZoom`，并独立读取 `chrome.tabs.getZoom`。MV3 worker 可能已经退休，而 Playwright 仍保留其对象，因此不能让闲置 worker 拥有缩放控制器。[退休回归](../../../../apps/web/tests/browser-native-zoom.e2e.ts)停止真实 worker 后验证后续 100% 和 400% 缩放。Chromium 可能在 CSS transition 已结束后仍保留未完成的 `finished` Promise，因此渲染就绪通过现有有界轮询检查有限动画当前的 running／pending 状态。分页证据在打开草稿前等待准确的下一页任务身份；保留的上一页不能代替已提交的续页。

工作区草稿动作在通知订阅者前，提交完整的映射、视图顺序和草稿计数，重入观察者亦如此。每个被草稿固定的视图至少拥有一个已计数草稿，因此已验证的 `maxViewStates > maxDrafts` 限制保证存在可淘汰的未固定视图。数字选择器仅在通过原生安全整数验证后比较；同步 portal effect 使用同次已提交渲染挂接的 ref。异步退休围栏仍由其原所有者保留。
