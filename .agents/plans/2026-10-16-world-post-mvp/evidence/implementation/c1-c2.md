# C1–C2 generation and planning evidence

## Shipped path

The [generation owner](../../../../../packages/simulation/simulation-local/src/world-generation.ts) persists actual input, canonical identity, original output, validation, cancellation and exact Persona draft revision/hash. Native stream 100 rejects earlier formats. A dedicated [Team executor](../../../../../packages/simulation/simulation-team/src/generation.ts) persists the complete concrete output contract and model input in its original Session, sends no tools or ambient history, shares FIFO model capacity and Native token accounting, and retains interrupted responsibility. The inherited decision timeout also bounds helper calls. A retained Session output reconciles a failed Native append without another provider call.

Product `generationRequest`, `generationRead`, `generationExecute`, `generationTransition` and `generationPersonaDraft` preserve authenticated run ownership. Inputs must be explicitly user-authored; the Host records actual principal/credential-generation provenance and fixes runtime, organization scope, audience and policy. Planner disclosure additionally rechecks the current private-case reader policy. Output/start/usage transitions are absent from the client command union. The Persona bridge uses the existing A2 preview, authenticated submission and Native draft commit, then records its exact original generation source. Draft review and hiring remain separate decisions.

Planner assignments bind an existing installed domain request and freeze actual Native read-sets before inference. Parents bound attempts, child count, depth, scope, effects, deadlines and aggregate token allocation. Cancellation closes new child admission without deleting accepted jobs or plans. Helpers retain immutable output; the original director must consume the exact output in its Session and explicitly select `generationJobId`. Native preserves the original read-set and stale/supersedes history, and the existing single committer applies effects. The World driver orders ready plans by acceptance sequence and skips temporarily blocked plans without dropping their responsibility.

- `generation.spec.ts`: actual canonical Team/Session and scripted external provider on both backends; canary input isolation, empty tool set, polluted-history refusal, unauthorized direct stream refusal, original output response loss, no regeneration, coalesced caller revocation and unload retaining unknown responsibility.
- `world-planners.spec.ts`: actual Loader composition for conflicting original read-sets; real director consumption, parent/depth/token/cancellation refusal. Independent organization and environment helpers generate in distinct Sessions in parallel; the original director and single Native owner commit both nonconflicting plans.
- `world-management.spec.ts`, `bridges authenticated`: real Host API carrier → Product → canonical helper → A2 draft owner on JSON and SQLite. Wrong runtime, claimed private source and revoked caller reject; reads/review/retry make no additional model calls.
- `world-generation.snapshot.ts`: real Cordis Loader and separate create/reopen processes on JSON and SQLite; create makes exactly one scripted call, reopen makes zero, and both retain exactly one input and output event plus the original token count.
- `model-capacity.spec.ts`: existing FIFO admission, bounded queue and confirmed release behavior remains applicable to helpers because they use the same pool.

[Measured samples](c1-c2-parallel.json) compare two serial versus parallel calls with a fixed 40 ms external-provider fixture. The measured peak changes from one to two while call count stays two; this demonstrates local overlap and isolation, not production-model throughput or quality. No real provider was called or funded. Detailed command logs and transient artifacts stay under `.local/post-mvp-c/`.

## Limits

Generation is explicit, never automatically allocated for every role. Product inputs are user-authored rather than arbitrary external source claims. Persona placement still obeys A2 finite-template checks. Provider usage absence remains a charged unknown instead of an invented cost. Real-model quality and production performance require a separately frozen and authorized evaluation budget.
