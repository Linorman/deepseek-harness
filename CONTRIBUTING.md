# Contributing

English | [中文](CONTRIBUTING.zh.md)

Clocky is under active development and does not currently accept external pull requests. You can help by:

- Reporting bugs and sharing feedback through [GitHub Discussions](https://github.com/Linorman/clocky/discussions), or upvoting existing reports. The small team monitors discussions but may not reply to every post.
- Creating and sharing plugins; add the `clocky-plugin` topic to your repository so others can find it.
- Writing tutorials and answering community questions.

Community plugins are as valuable as those maintained here; this repository provides examples rather than prescribing the ecosystem's direction.
