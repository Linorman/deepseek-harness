The `simulations.validateArchivePrefix(provider, input)` capability validates a complete portable Native prefix in memory with the installed provider, exact journal version and source spec. Local validation uses the same reducer and projection invariants as inspection, enforces configured scan limits, and never opens source storage, creates identities or calls a model. Experiment branching uses this capability to validate immutable older cuts and offline archives before initializing new writable owners.
