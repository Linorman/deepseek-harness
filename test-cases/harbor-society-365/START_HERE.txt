河港社会：365 日自主演化案例

本目录可整体复制到一个空工作区使用。只依赖 Node 的标准库，不需要本项目源码、文档、pnpm、网络搜索或安装第三方包。Agent Team 本身使用什么模型和协作工具，由测试环境提供；模型调用不属于网络搜索。

测试者先运行 node integrity.mjs 与 node --test engine.test.mjs 检查环境工具，然后把 PROMPT.txt 完整提交给被测 Agent。Agent 可读 RULES.txt 和 GUIDE.txt 了解世界规则与工具接口。ACCEPTANCE.txt 是测试者的质量判据，不要和 prompt 一起提交。不要要求 Agent 按预设业务流程运行，也不要把现成的答案作为输入。

世界工具是被动的环境裁判：它处理资源、承诺、模拟时间和外部变化，不替任何参与者选择价格、交易对象、组织结构或经营策略。完整的一年需要持续的主体决策；仅用循环推进日期或运行固定政策程序不能通过。

输出均保存在 output/。中断后重新执行工具会从 journal.jsonl 重放状态；不需要清空历史。若要比较不同模型，请为每次实验复制一份整个案例目录，避免不同 Team 共用同一世界。
