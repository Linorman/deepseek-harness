# 视觉语法

## 三层身份

| 层 | 用什么建立 | 应产生的结果 |
| --- | --- | --- |
| 研究出版物 | 衬线主题、正文段落、章节号、日期、横线 | 可以认真阅读，内容拥有中心地位 |
| 科学仪器 | 等宽标签、基线、点线结构、刻度与小标记 | 信息被准确组织，关系可以追踪 |
| 计算环境 | 低亮云雾、稀疏粒子、慢信号 | 系统具有持续活动感，不掩盖文本 |

前两层构成主要身份，第三层按任务启用。只有深色底和蓝色发光无法建立完整风格。

## 视觉重量

页面大部分面积保持近黑；大部分可读面积交给文字；色彩集中在线、点和少量关键词上。最亮层属于主题、关键结论和必要操作。正文为第二层，索引与注释为第三层，装饰轨道和云雾为最低层。

不固定机械的面积百分比。检查缩小页面后首先看见的是否仍是主题和主要内容，而不是所有卡片边缘、按钮光晕或背景纹理。

## 字体语义

- 衬线：主题、研究问题、章节标题、图解结论、成果标题。
- 无衬线：解释、说明、常规操作、图内实体标签。
- 等宽：章节编号、日期、状态元信息、导航索引、短提示。

一种内容角色始终使用同一种文字语法。中文依靠字级、字重、留白与有限字距建立同等分工，不把英文全大写和负字距机械迁移到汉字。

## 色彩语义

紫蓝是结构和过程：普通节点、连接、链接与阅读进度。琥珀是需要注意的证据或行动：验证点、选中的有效结果、关键入口。暖色的具体意义由上下文说明，不当作跨所有业务的成功状态。

给每幅图指定一个主要暖色焦点；如果业务确实有多个独立验证结果，可以重复标记。不要为了满足“一个点”的形式规则隐藏真实内容，也不要把每个阶段都变成最高强调。

## 空间语义

左侧较窄区域建立身份，右侧较宽区域提供解释；图形横向展开建立关系。元信息与正文可以分列，但同一类信息的起始位置应稳定。大留白出现在主题变化处，小间距维系同一组件内部关系。

容器以细线和留白分组。按钮可以是胶囊；任务单元可以有轻圆角细框；连续论述通常不需要完整独立卡片表面。不要为套用该风格而删除已有产品必须具备的面板边界。

## 图形语义

| 原语 | 可表达的内容 | 禁止混淆 |
| --- | --- | --- |
| 静态点 | 实体或阶段 | 不默认等于在线状态 |
| 移动点 | 信息或反馈沿关系传递 | 不默认等于实时数据 |
| 连续线 | 明确的连接 | 不用无关连线制造科技装饰 |
| 虚线 | 弱关系、延续或待验证关系 | 具体意思需由上下文稳定定义 |
| 环 | 活动、反馈范围或验证强调 | 不默认等于加载中 |
| 框 | 工作单元或受限阶段 | 不是每段文字都要套框 |
| 螺旋 | 重复过程中的累积 | 单纯循环应用闭环即可 |

## 容易偏离的方向

避免把长文页面做成所有区块等大的 bento 网格；避免重玻璃表面覆盖所有内容；避免统一超粗几何标题替代字体分工；避免高饱和渐变填满背景；避免大幅 3D 倾斜、弹跳、磁吸和自动横向滚动成为主要节奏。这些效果并非普遍不好，只是不属于当前风格的已确认主要语法。

视觉判断以[参考图](source-reference.md)为准。可以改变行业内容、技术栈、模块数量和图解拓扑，但不能只保留配色就声称还原了全部风格。
