# 参数与字体

## 使用参数文件

[tokens.css](../assets/tokens.css)只提供具有 `--sci-` 前缀的 CSS 变量，不包含 reset、组件、字体二进制或自动播放动画。将其内容合并到目标项目现有主题系统，或只给需要使用该风格的区域加上 `data-scientific-editorial` 属性。

`data-style-profile="reference"` 使用默认值；`data-style-profile="reading"` 应放在同一个包装元素上，覆盖必要小字和正文进入参数。应用区域若处于 Shadow DOM 或 portal，需要显式继承同一主题，不将局部任务升级为全局主题修改。

包装元素使用 token 并不自动完成样式。组件仍需消费对应的字号、颜色、间距与时长变量；背景、文字颜色、`box-sizing: border-box` 等规则按区域配置。不要假定这份文件可直接替代完整页面 CSS。

## 颜色角色映射

| Token | 分配给什么 |
| --- | --- |
| `--sci-bg` | 连续主画布 |
| `--sci-surface`、`--sci-surface-raised` | 必要的层级表面或浮层 |
| `--sci-ink` | 主题、主操作和高优先级信息 |
| `--sci-body` | 段落与一般说明 |
| `--sci-muted` | 辅助信息；reading 模式提高其亮度 |
| `--sci-faint` | 弱装饰；reference 模式下个别原站提示采用相近等级，但不作为可读性保证 |
| `--sci-rule`、`--sci-rule-soft` | 行分隔与较弱结构线 |
| `--sci-blue`、`--sci-blue-bright` | 链接、数字、信号与增强状态 |
| `--sci-blue-line` | 图形关系路径 |
| `--sci-amber`、`--sci-on-amber` | 关键暖色与其表面上的深色文字 |

不要通过统一容器 opacity 同时降低整个组件：这会把文字、交互和边框一起压暗，并产生不可控的叠加。按语义分别使用颜色变量。

## 字体加载

优先使用真实的 IBM Plex Serif、Sans 和 Mono，并加载所需字重。源站给它们设置了简短别名；token 文件同时兼容全名和别名。字体文件不随本 skill 分发，已有项目的合法字体资产优先；新增字体遵守任务允许的依赖与获取方式。

| 字体角色 | 字重 | 行距与排版 |
| --- | --- | --- |
| 主标题 | 桌面 300；源站窄屏提高到 400 | 使用 title token；较紧行距和轻微负字距；平衡换行 |
| 章节标题 | 400 | h2 token；比正文紧凑；不强制全部单行 |
| 三级标题 | 500 | h3 token；行距约 1.35 |
| 正文 | 400 | text token；body 行距；宽度约 40em |
| 导语 | 400 | lede token；行距约 1.65，宽度约 40em |
| 编号与眉题 | 400–500 | mono；短标签加字距，英文可大写 |
| 图解结论 | 400 | serif；行距约 1.5；控制文字宽度 |

字体缺失时，允许按任务时间和环境使用 fallback，但交付说明其差异。验证应检查实际字体资源加载或渲染字体；计算样式中出现名称不代表文件已成功加载。

## 大小与测量

源站英文技术页在 1280 × 720、默认根字号约 16px 下，主标题约 56.32px、h2 约 33.28px、正文约 15.68px。主标题使用普通技术页面 title 级，不套用首页更大的 hero 字级。

保留流体字号的上下限。长标题先调整内容宽度与换行，不先缩小成正文级；窄屏换行是正常结果。用户的字号偏好必须能够影响 rem 单位，不固定根字号来强迫截图一致。

## 中文

中文标题可使用任务允许的宋体或中文衬线字体，与无衬线正文形成角色区别。正文行距约 1.85，标题行距约 1.22，可作为源站中文规则的参考。取消英文标题的负字距，中文标题使用正常或轻微正字距；长汉字句子不加英文小标签式的宽字距。

没有中文衬线资产时，使用明确的系统 fallback 并检查真实设备字形。包中没有附带源站的中文字体子集，不把该别名的存在当成文件可用。

## 两个模式的边界

`reference` 的弱文字可能复现原站约 44% 与 26% 的透明层级，它们在纯近黑背景上的计算对比度约为 3.89:1 与 2.07:1。需要严守原样且存在可读性问题时，记录该问题并提出具体偏差选择，不偷偷改色再宣称像素一致。

`reading` 将 muted 提高至 60%、小标签提高到 .75rem，并减少正文入场的模糊、位移、时长和错峰延迟。这些是本 skill 的适配值。必要提示使用 muted 或更高层级；faint 留作装饰。该模式也需要在实际背景上检查对比度，不自动证明无障碍合规。
