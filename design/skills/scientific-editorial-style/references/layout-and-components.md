# 布局与组件配方

## 共同坐标系

使用 token 的 shell 上限和流体横向 padding，容器居中且使用 border-box。1280px 视口时，外框为 1280px，左右 padding 各约 64px，内容净宽约 1152px；不要再创建一个 1280px 净宽内容层导致页面变宽。

主标题、章节眉题、跨栏图与页尾共享外侧基线。内部双栏共享第二条正文基线。章节基础 padding 使用 section token；连续章节不要机械叠加两份上下 padding。参考截图判断每个章节是否需要分隔线及实际起始间距。

| 配方 | 桌面结构 | 内容规则 | 窄屏策略 |
| --- | --- | --- | --- |
| 主题导入 | 单一左对齐标题、导语、动作、流程 | 主题优先，导语不占满整行 | 换行；按钮扩展；流程纵向 |
| 章节介绍 | 5fr : 7fr | 左身份，右解释；保持 gap | 899px 以下单列 |
| 项目章节 | 4fr : 8fr | 左名称与定位，右论述和链接 | 899px 以下单列 |
| 能力目录 | 3 等分列 | 编号、标题、说明；横线分组 | 899px 以下单列 |
| 信息图模块 | `minmax(0,1fr) 13rem` | 图形与提炼属性，下方图注 | 899px 以下图、图注、属性顺排 |
| 论文或成果行 | 3fr : 9fr | 左日期与类别，右标题及摘要 | 860px 以下单列 |
| 日期表 | 5.6rem 与剩余宽度 | 每行一条记录，限制整体宽度 | 内容较长时允许日期与说明重排 |

这些比例是起点。不同内容允许调整，但保留“身份少占宽度，解释多占宽度”的关系，不把所有区域改成对称卡片。

## 主题导入配方

从上到下放置：等宽眉题、衬线主标题、无衬线导语、少量动作、过程摘要。主标题只突出有语义的关键词，避免每个词不同颜色。动作区使用一个主要任务和必要的次要入口，不为凑布局增加按钮。

过程摘要由一条线串起若干阶段。原参考有六个节点，但新内容使用真实阶段数。每个节点以短词组描述，特殊证据阶段可用暖色。639px 以下转为竖向线，去掉多余水平箭头。

页面顶部需给固定导航留出空间。原参考 hero 顶部 padding 约为 `clamp(7.5rem,18vh,11rem)`；这是来源参数，品牌头部高度改变时应同步调整。

## 导航配方

全站导航固定在顶部，主要站内链接居中，品牌与工具位于两侧。当前页面采用亮文字和细紫蓝下划线。滚动超过约 24px 后，垂直 padding 从 1.05rem 收至 .65rem，增加约 74% 近黑底、12px 背景模糊和弱分隔线。

章节导航在首屏之后正常排布，到达顶部后吸附于全站导航下方。使用等宽字、较宽字距和短标签，横向溢出时允许滚动。当前章节状态与实际阅读位置同步。锚点偏移按两层导航的实际高度计算，字体放大、换行或项目导航改高后不能仍照抄固定偏移量。

899px 及以下用明确按钮打开全屏目录。目录采用大号衬线字、逐行分隔、当前项紫蓝和关键动作暖色。源站图标会旋转，面板本身没有由现有证据支持的滑入承诺。新实现应确保菜单状态、背景滚动、焦点进入和返回、Escape 关闭与键盘顺序正确；这属于交互可靠性补足，不需要改变外观。

## 按钮配方

| 项目 | 描边按钮基线 |
| --- | --- |
| 尺寸 | 默认最小宽约 9.5rem，padding 约 .72rem × 1.25rem |
| 形状 | 1px rule 色边框，pill 圆角 |
| 文字 | Sans，约 .92rem，500 字重 |
| 悬停 | 上移 1px，微弱底色增强，边框或局部高光增强 |
| 键盘焦点 | 清楚的独立描边，不要求指针追光才能辨识 |
| 禁用和等待 | 按真实业务明确表达；不能仅低透明度且仍可点击 |

导航申请入口是更紧凑的暖色按钮：padding 约 .5rem × .95rem，文字约 .84rem。不要因为它是琥珀色就自动添加通用主按钮的扩散环。

普通正文链接使用紫蓝和轻量方向符号。箭头可区分向下跳转、站内前往和外链；是否新标签打开由产品规则决定，不能让风格覆盖既有导航约定。

## 信息图配方

先写出实体、输入、过程、结果、反馈与待验证关系，再画路径。图内标签必须是真实内容。较宽图形可用约 1200:450 坐标比例；具体 viewBox 由标签长度和路径决定。SVG 字号、线宽会随图形缩放，不能把坐标单位误当成最终 CSS px。

| 内容关系 | 合适拓扑 | 动态含义 |
| --- | --- | --- |
| 有顺序的阶段 | 序列 | 信号逐站传递 |
| 结果回到起点 | 闭环 | 反馈返回 |
| 每轮有积累 | 螺旋 | 向外增长的重复过程 |
| 人与系统多轮交流 | 对话折线与轨迹轴 | 往返、记录与累积 |
| 多个可重复执行的任务 | 并列工作台 | 输入分配、验证和结果聚合 |
| 多域输入与候选未来 | 汇聚中心再分叉 | 表征、预测与选择 |

路径一般使用约 1–1.4 个 SVG 单位，填充较少；圆点区分稳定节点与移动信号。透明命中区域可大于可见细线。图右侧用短的衬线属性总结价值，图下方给出一句能够脱离动画理解的解释。

手机上按复杂度选择：简图重新排布或确保缩放后标签可读；复杂总览可以保持较大内部宽度并横向滚动，提供明确提示与等价文本。980px 是原总览的内部宽度，不是所有图解的统一手机参数。

## 成果列表配方

每行包含元信息与主体。主体次序为衬线标题、弱化作者或来源、无衬线摘要、等宽类别。行之间使用弱横线。可在目录页截断摘要，但必须提供可访问完整内容的入口；截断不自动意味着“点击展开”。

不同业务可将日期替换为版本、样本批次或阶段，但保持元信息的字段含义一致。表格和列表只有真实必要字段，不伪造论文数量、作者、发布日或进度。

## 响应式验证点

检查 1280px 和 390px 的主要视图，并针对实际采用的断点检查两侧。来源中的主要断点为 1200、899、860、639、560 和 1024px；按组件采用，不强迫目标项目覆盖全部断点。

大屏边缘轨道可在 1024px 起显示，手机隐藏。主流程在639px 以下转纵向。属性栏在899px 以下到图下方，在560px 以下改成单列。保留内容顺序和相同语义，不依靠仅桌面可见的说明完成理解。
