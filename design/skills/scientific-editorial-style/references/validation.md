# 还原验收

## 区分两种验收目标

同内容复现采用 reference 模式：同视口、同滚动位置、同菜单状态、同动画阶段进行截图比较。新内容迁移则比较字体角色、空间比例、色彩权重、图形语义与节奏，不要求与原站文本换行完全重合。

只有实现了静态样式，不能宣称悬停、循环和跨页转场已验证。只有源码参数，没有实际截图，也不能宣称页面视觉已经还原。

## 视觉检查顺序

按“字体与字形 → 内容宽度与基线 → 文字层级 → 色彩和边框 → 图形结构 → 微小间距 → 动态”的顺序修正。前面的误差会影响后面的判断，例如字体缺失会改变行数、区块高度和锚点位置。

| 检查项 | 通过条件 | 常见偏差 |
| --- | --- | --- |
| 字体 | 实际字体已加载，三类语义角色稳定 | 只声明名称，实际全部 fallback |
| 外框 | 容器与 padding 解释正确，外缘一致 | 将 1280px 当净内容宽度 |
| 双栏 | 身份列与解释列有明确关系 | 所有区块都变成对称卡片 |
| 文字 | 大标题紧、正文松、标签短且可读 | 所有内容同一字重，标签过暗 |
| 色彩 | 紫蓝承担过程，暖色只强调有意义的关键位置 | 全部节点都发光或全为琥珀 |
| 图解 | 每条重要关系能解释，静态状态完整 | 随机连接、示意条被当作实时进度 |
| 表面 | 细线和留白组织内容 | 重阴影、厚玻璃和大面积彩底喧宾夺主 |
| 背景 | 低权重，文字仍是主角 | 高亮星云与粒子覆盖正文 |
| 手机 | 阅读顺序保持，必要标签可读 | 宽 SVG 无条件缩小到手机宽度 |

## 交互与动态状态

检查入场前、中、后，悬停/离开，键盘聚焦，点击，菜单展开/关闭，锚点定位与返回阅读。移动信号暂停后应能合理继续；重新进入视口不应重复不必要的首次入场。

检查在页面隐藏、组件卸载、窗口缩放和切换减少动态效果偏好时，循环与测量能正确停止或更新。必要内容不依赖动画事件才能出现。菜单的焦点应进入、留在合理范围并在关闭后返回入口。

## 设备与对比度

至少使用一个桌面视口和一个窄屏视口；需要对照原调查时使用1280 × 720与390 × 844。针对实际启用的断点检查两侧，例如899与900px；不把仅测两个尺寸写成全断点验证。

实际背景上的必要小字应达到适用的对比度目标。reference 模式复现低对比细节时记录风险和偏差；reading 模式提高辅助文字亮度，并检查透明背景叠加。一般正文4.5:1、大字3:1是常用的最低文字对比门槛，具体适用条件见 [W3C 说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。本 skill 不替代完整合规审计。

## 行为试题

可用以下任务检验执行者是否理解了 skill；不要求每次使用都构建这些示例。

| 输入任务 | 合理行为 | 应拒绝的误读 |
| --- | --- | --- |
| 为量子材料实验室做三个研究方向介绍 | 保留字体与布局语言，按真实研究关系选择不同图形 | 复制原站项目名与六步流程 |
| 只为现有下载按钮加入同风格 | 局部胶囊描边与轻反馈；有条件采用边缘追光 | 重做页面、添加云雾和导航 |
| 按截图精确还原首屏 | reference，加载准确字体，同尺寸比较 | 默认提高所有灰字后宣称完全一致 |
| 将该风格用于高频任务控制台 | reading，操作优先、静态环境、正文快速出现 | 每次状态更新播放800ms模糊入场 |
| 制作中文研究报告页面 | 保留衬线主题与无衬线正文，调整中文行距和字距 | 对长段汉字逐字错峰与加宽字距 |
| 网络不可用且缺少 IBM Plex | 使用明确可用 fallback，声明字体偏差，继续可做部分 | 声称已加载未获得的字体或依赖原聊天 |

## 完成标准

交付内容需符合用户范围；选用模式清楚；必要参考已读取；主要图像与交互状态已检查，或准确注明缺失证据；没有将建议值伪装成来源实测；没有把局部任务扩大成全站重构。若实现没有环境动效，但用户仅要求局部组件，视为范围正确，不视为风格缺项。
