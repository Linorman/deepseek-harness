# 运动与交互

## 运动合同

为每个新增动效明确五件事：触发、运动对象、路径或属性、结束或中断条件、静态替代。用三种语义区分循环：背景氛围、概念过程、真实运行状态。前两种不能让用户误以为产品真的在执行某个任务。

基础时长与曲线由 [tokens.css](../assets/tokens.css)拥有。下表的相对顺序和实例周期来自源站调查；reading 模式的缩减策略是本 skill 的建议。

## 入场

| 对象 | 起点到终点 | 编排 |
| --- | --- | --- |
| 内容块 | opacity 0 到 1、正 Y 位移到 0、模糊到清晰 | reveal token；章节内 stagger token，设置总延迟上限 |
| 标题单词 | 上移约 .35em、blur 6px 到 0、透明到可见 | word-reveal token；每词 word-stagger |
| 章节横线 | scaleX 0 到 1，原点在左 | section-draw token |
| 流程主线 | 由起点向终点展开 | 来源 1.4s |
| 流程节点 | 空心到填充，加少量光晕 | 约 500ms；250ms 起，加每节点 170ms |
| 流程标签 | 上移 6px 并显示 | 约 600ms；350ms 起，加每节点 170ms |
| 流程上的一次信号 | 沿主线到关键节点附近，末端消失 | 约 1.8s；主线建立后约 1.5s 开始 |

不对每次用户操作触发的正文刷新重新播放长入场。源站的首次进入通常只播放一次；新实现同样保存已经进入的状态。首次可见的重要主题与操作不应等待离屏观察器的后续回调。

标题分词应保留完整可访问文本和自然换行，不逐词打断屏幕阅读器。中文按短语或自然语义单位处理；不要对整段汉字逐字长时间错峰。

## 图形运动

描线使用路径长度归一化或同等技术，由不可见到完整路径。一般用 path-draw token，复杂路径可用 slow token。标签和节点可以略错峰，但在读者理解关系前不要让大量光点先行运行。

| 图形 | 来源实例 | 迁移规则 |
| --- | --- | --- |
| 简单路径信号 | 默认约 6s，linear | 根据路径长度和可读性设定，避免急促折返 |
| 对话与反馈轨迹 | ScienceBuddy 约 9s | 让信号经过有语义的往返节点 |
| 递归螺旋 | DFM 约 24s，错开相位 | 复杂路径使用更慢周期，表示累积 |
| 验证环 | 默认约 3.6s，ease-out | scale 1 到约 1.9 并淡出 |
| 慢验证环 | 约 6s | 降低关注频率 |
| 轻呼吸 | 约 4s 或 6s | 用少量透明度变化，控制作用对象数量 |
| 示意增长条 | 来源约 9s 循环 | 明确它是解释过程，不是实时进度 |

静态节点与移动点分开。移动点、扩散环及其他装饰不接管 pointer events，不阻挡真正可交互的节点。离屏暂停是建议的新实现策略；源站并非所有 CSS 图形循环都已经具有该能力。

## 信息图的关注状态

指针进入一个实体或关系组时，提高局部文字、节点和路径亮度，必要时显露次级标签或将弱连接变为更明确的线。保留足够上下文，避免整张图只剩单一孤点。

在指定分组获得关注时暂停移动信号；离开后从当前进度继续，不把暂停写成每次都重置到起点。若使用预测分叉结构，可降低同组其他候选分支亮度。焦点事件应能触发必要的同等解释；触屏可使用点选与明确取消选中，或持续显示完整说明。

核心信息始终可以在静态文本或稳定标签中获取。悬停时出现的解释如果不影响任务，可保持为装饰增强；如果影响理解，必须为键盘与触屏提供替代。不要把所有 SVG group 机械赋予按钮角色；只有具有操作意义的对象才需要交互语义。

## 按钮边缘追光

该效果是一条受边框遮罩约束的局部反光。指针位置转换为按钮内坐标，控制半径约 90px 的径向渐变中心；暖白到琥珀到紫蓝逐渐消失。局部反光替代普通悬停时的整圈提亮，不叠加成过强光圈。

状态转换：空闲 → 指针进入后亮起 → 指针移动时更新中心 → 离开时熄灭。使用 edge-light token 控制显隐，按钮位置只上移约 1px。它不包含大幅跟随或磁吸位移。

条件为可悬停、精细指针、未请求减少动态效果，并且遮罩合成可用。否则回退为普通边框或底色状态。测量在进入时进行；按钮因入场、滚动、缩放或布局改变后要刷新边界。离开页面或组件销毁时清理监听与高亮，避免旧状态残留。

## 点击环境反馈

可选效果：点击位置扩散一个细环，约 750ms 内消失，半径最终约 49px；150px 范围内的背景粒子被短暂轻推，随后衰减回流。此效果由点击触发，不是鼠标跟随排斥。

在表单提交、删除或保存等产品操作上，环境涟漪不代表操作结果。真实状态仍通过产品组件表达。reading 模式和高频工具中通常省略这层环境响应。

## 环境层

需要还原环境时，用两层低亮蓝紫密度场，加一层稀疏、缓慢漂移的小粒子。先做静态背景，再加入运动。不要要求生成大幅宇宙照片或 3D 星球来代替参考中的低亮场。

可采用低分辨率 Canvas 绘制云雾、较高分辨率层绘制粒子。来源云雾画布宽 320px；桌面约 64 粒子、窄屏约 26 粒子；33ms 与41ms 是源码更新间隔，不是经过验证的设备帧率。参数按目标设备预算调整。

| 内容状态 | 环境倾向 | 何时使用 |
| --- | --- | --- |
| flow | 比默认更明显的方向流动 | 过程、连接、整体研究叙事 |
| grid | 更慢，粒子逐渐趋近规则网格 | 可执行环境、结构、工程体系 |
| calm | 平静的低权重流动 | 记录、列表与长文 |
| static | 完整但不持续运动 | reading、减少动态效果或资源受限 |

章节切换用约 .9s 时间常数平滑趋近新参数。此值描述响应速度，不代表 .9s 后精确到达终点。只对需要保护的标题和导语区域削弱云雾；文字亮度依然要在实际背景上验证。

在标签页不可见、组件卸载或环境关闭时停止循环。静态替代不能是一块空白。保持一个合理的最终画面，减少动态效果时不再需要用户悬停才能停止运动。

## 导航与页面切换

导航滚动紧凑化使用 header-transition token。目录滚动按真实导航高度避让；减少动态效果时直接定位。阅读进度是顶部细线，真实绑定文档阅读位置，不能伪装加载条。亮带扫动属于可选装饰。

源站共享 CSS 声明跨页旧画面约 220ms 淡出，新画面约 340ms 淡入并上移6px，导航单独命名。只有目标技术栈与浏览器支持且用户任务包含跨页体验时才实现。该细节属于源码确认，不能据此保证任意浏览器或任意页面之间都会生效。

## 减少动态效果与中断

请求减少动态效果时：内容立即可见、线条完整、标签可读；取消位移和模糊进入；隐藏或停止移动点与扩散环；背景为静态；锚点直接定位；按钮使用清楚的无追光状态。

不要仅把全局动画时长改为 1ms：部分元素可能仍停在初始透明状态，依赖结束事件的逻辑也可能失效。显式定义最终静态状态。运行中切换偏好时同步更新 JS 循环与 CSS，不能只有其中一层响应。

频繁触发的反馈可逆且不中断输入。取消、导航离开和组件销毁后不继续写入旧节点。新增实现应处理这些生命周期边界；这不是宣称原站所有路径都已经过同等测试。
