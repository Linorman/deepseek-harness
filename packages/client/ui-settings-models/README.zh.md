# @clocky/clocky-client-ui-settings-models

[English](README.md) | 中文

面向浏览器客户端的、与提供方无关的 Models 设置界面。它把 `llm.providers` 目录、脱敏的 `settings.describe` 视图和不含值的凭据描述符汇成一份快照，每次只渲染一个编辑器，并且不把路由是否存活误当成提供方身份。

页面列出已配置的提供方 profile；只有当 LLM 目录表明适配器没有已安装 catalog 条目时，行才标记为自定义。休眠的 catalog 路由可以由用户明确添加；页面不会选择厂商、偷偷挂载适配器，也不会提供提供方或模型默认值。

pi-ai 编辑器只通过路径寻址的 `settings.mutate` 操作写入自己负责的字段，包括接口地址、适用时的显示名称、模型 ID 与名称、模型容量，以及 schema 暴露的提供方协议。字段集合之外的值会在编辑时保留。模型列表只在用户修改时物化；重置会移除用户层覆盖。

凭据输入框是只写的。页面解析 profile 的凭据引用，只显示是否已配置及是否可写，并通过 `credentials.set` 发送用户输入；它不会把机密放进 settings 响应或本地草稿。空输入保留已有凭据。无效的模型 ID、容量或密钥文本会在写入和端点询问前被拒绝。

页面会在 settings、凭据、提供方拓扑或连接重置通知后刷新。凭据读取失败只会降低凭据徽标，不会破坏设置页；settings 或提供方读取失败会保留最近可用快照并报告错误。只读 settings 会禁用编辑，但不会隐藏提供方目录。

## 模型列表与端点询问

模型列表编辑器逐行展示模型，并提供可选的上下文窗口和输出上限。已配置的提供方可以使用表单当前显示的端点与密钥向所属适配器询问模型；返回的候选项会保持暂存，直到用户选择并添加。

添加自定义提供方需要唯一的路由 ID、受支持的协议、接口地址和至少一个模型。profile 写入和凭据写入是分开的操作，因此凭据写入失败时可以重试，而不必重复使用过期的 settings revision。

## 模型体验

无。本包只渲染配置界面，不组装或发送提供方请求。

#### KV Cache 影响

无；请求构造与缓存行为由提供方适配器负责。

## 已知限制与暂缓事项

- **编辑器有意只覆盖精选字段**——适配器的高级字段仍可通过 settings 文档配置；页面更新自己负责的字段时会保留这些值。
- **端点询问依赖协议**——页面把发现操作交给所属适配器；适配器无法询问时，模型仍可手工编辑。
- **提供方 ID 是稳定键**——路由 ID 的变更需要删除后重新添加，因为会话、settings 路径和凭据引用都以它寻址。
