CollectionWorkspace 共享筛选、有界分页与详情外框，原 Workspace 继续拥有读取生命周期。对象摘要优先呈现已授权名称和领域事实，技术标识仍可在展开区复制。关闭详情后焦点返回对应行；该行不在当前页时返回筛选控件。已知原生记录类型提供本地化名称和快捷选择，精确自定义筛选保留空白，未知或截断类型按原值显示。

空目录展示已安装模板与创建操作；没有已安装的采购模板时以**新建世界**（世界模板、文件或空白骨架）为首要操作。尚未读取的计数保持待加载，页内计数只描述当前窗口。没有默认模型时，创建页保留字段并提供共享 `settings.model-setup` 操作：先关闭创建页再打开模型设置，返回后重读目录就绪状态并重新预检保留草稿。保存设置不创建运行。创建确认携带展示的模型路由；路由变化要求再次明确确认。准备阶段完成初始检查点后才可启动。

两种语言的运行标签区分岗位容量、实体/历史成员/通道限制、世界记录/申请/命令限制，以及预算/上下文/microstep 停止。预算拒绝保留原行政控制和可读记录；刷新不重试模型，也不将停止状态解释为入职成功。

`commandTimeoutMs` 默认 30000 毫秒，限制每次日历预览/提交等待；超时保留未知状态与原预览。日历修改仅针对已恢复暂停运行，正文未授权或被截断时禁止编辑。人物市场履历展示经独立授权的完整人物设定和邀约条款；仅当前人物版本可进入审核预览，历史记录只读，候选人接受不由用户按钮代办。

## 配置与所有权

浏览器配置位于 modules.browserConfig 的 `@clocky/clocky-client-ui-simulation` 键下。`pageSize` 默认 32，`controlRefreshMs` 默认 2000 真实毫秒。Host 独立执行自身额度和动作前置条件。`watchWaitMs` 默认 10000、`watchRetryMs` 默认 2000 真实毫秒；每个可见运行的单一元数据观察检测原生 revision 及策略变化。策略 reset 移除旧上下文正文并复查所选分区，不清除草稿或原命令；其他保留页面标记过期，刷新仍须明确操作。`maxRetainedCommands` 默认 64，`maxCommandBytes` 默认 262144 UTF-8 字节，计入完整保留原记录，并在 IO 前预留临时结果／错误元数据。`maxInputDrafts` 默认 16 个实体输入、准确尝试审核与操作重试草稿槽；`maxDraftBytes` 默认共享 65536 字节，计入完整创建、实体输入、审核与操作重试原始草稿。容量拒绝保留已有输入与操作。世界作者草稿单独计量：`maxWorldDraftBytes` 默认每槽 262144 完整 UTF-8 字节（与 Host 编译器源码上限一致），`maxWorldDrafts` 默认 4 个并存槽，`draftUndoDepth` 默认 20 步内存撤销；`inspectorMaxWidth`（默认 520 CSS 像素）限制世界检查器宽度；内容宽度至少 1440 像素时检查器可调整宽度。一个世界管理流草稿与输入／审核草稿共享条目数。 `staleAfterMs`（可选；默认 15 个 `controlRefreshMs` 间隔且不少于 30000 真实毫秒，且必须大于两个间隔）是运行观测显示为“上次观测”的时长。`stopDrainMaxSteps`（32）、`stopDrainMaxTokens`（262144）与 `stopDrainMaxWallTimeMs`（600000）预填停止目标的收尾额度；每个目标保留各自的值。

业务响应与原命令由 Client runtime 持有。UI store 保留导航、已提交搜索、滚动位置及有界按运行隔离的原始输入草稿。账号替换或认证退役清除私有输入与旧操作；普通断线保留。切换工作区取消视图读取，不取消 Host 已受理工作。未保存输入仅在内存中保留；显式保存的创作版本由 Host 持久化，localStorage 与 URL 不保存草稿正文。存在保留输入或未知操作时，离开／重载触发浏览器离开保护。关闭对话框保留输入；明确放弃确认输入丢失，并保留未解决的原操作选择。

次级“更多”菜单打开请求记录（`simulationModule=requests`），与世界事件“记录”分开。当前持久页与对应的保留原命令合并为一项，分页外及管理／输入等其他类型原操作独立列出。概览提供入口；尚无运行身份的未知创建仍可从目录恢复。Workspace 统一拥有进入概览或请求记录时的请求页读取，隐藏呈现入口不会移除概览恢复所需的对账。请求记录独立发现持久行政 receipt，不依赖浏览器私有草稿。有界请求窗口使用独立日志 revision 及仅元数据的授权游标；查询不执行，已受理原请求只能明确按 Host 保留的 payload／commandId 重试，终态不变。已有 runtime 原请求保留完整输入，冷发现仅保存 runId／commandId。导航或凭据退役取消读取，旧操作回调不能刷新新选中运行。冷审核／外部重试仍须明确恢复 owner；原生 phase／ingress 历史不并入此行政日志。

## 运行状态、停止目标与业务摘要

同一个展示函数（`run-state.ts`）为目录行、页头与对话框表述运行状态：运行中、正在停止、正在保存、已暂停、空闲（已请求运行但无可推进工作）、需要处理、已受阻、调度失败、已完成、正在核对与未知。原生世界事实、管理控制（目录中为运行状态投影）、读取健康与连接是相互独立的输入；各来源 phase 不一致时显示“正在核对”并提供刷新，而不择一采信。每种状态至多一个主操作：暂停时为继续，运行时为暂停，失败或受阻时为恢复（按主机允许的 token 确认、检查点恢复或显式继续），需要处理时打开对应界面，到达停止目标后为修改目标，过期时为刷新。观测超过两倍 `controlRefreshMs` 为“较早”；读取失败、断线或超过 `staleAfterMs` 为“过期”：标签显示“当前状态未知 · 上次观测……”，动效停止，其他控件附原因禁用。仅原生详情读取失败时，仍以实时控制保留状态、暂停与保存检查点，并说明受限原因。管理、检查点、恢复或停止目标回执到达终态时调用运行时的 `invalidateRun(runId)`，目录行在新一批状态返回前保持为上次观测。状态批量读取失败时逐行标注并提供重试；手动刷新会报告已刷新、失败或超时。

停止目标是独立的原始命令（`updateRunControl`）：启动确认与“修改目标”对话框提供基于运行原生时钟的“运行至模拟时间 N”，默认 `drain-admitted` 模式并可编辑收尾额度（默认值见 `stopDrainMaxSteps`、`stopDrainMaxTokens`、`stopDrainMaxWallTimeMs`），也可选 `at-boundary`，并可选择暂停后保存检查点。主机回执确认且当前控制已载入该生效目标前，继续按钮保持禁用；待生效、主机越界拒绝（主机原句在详情中）与结果未知分别显示，结果未知时按原请求重试。页头标签与说明跟随主机状态从生效、收尾到暂停，收尾额度用尽时显示开始收尾时纳入的范围计数，并区分完整、不完整（`external-state-required`）与失败的保存；失败后“重试保存”打开一次显式检查点，主机将其记为同一停止目标保存的又一次尝试，保留失败尝试且不调用模型。关闭浏览器后目标保留在主机上，重新打开即可看到。

调度失败只用主机的安全事实渲染故障卡片：哪个环节失败、已受理工作是否仍在执行、已完成结果保留，以及由 `actionCode` 映射的下一步（无法识别的代码只打开运行详情）。只有 `explicit-resume` 处置提供继续；提供方信息不会进入页面，故障 ID 可复制用于授权关联。目录行与详情显示本地化的不可用原因（历史超出读取上限、版本不受支持、历史损坏、所有者不可用）；主机原始信息只在技术详情中。

World 事项以领域投影器的业务动作和三层独立结果（提交、裁判执行、业务结果）开头；裁判拒绝的已记录结果显示为“裁判拒绝”且不使用成功配色，未知结果从不计为成功，没有投影器时说明该领域未提供业务摘要。通用的 `committed` 状态改为中性的技术措辞。概览的领域业务卡显示第一页事项中最新的已授权投影计数及其修订号与口径；无权查看、未知、不适用与零通过同一个 `DisclosedValue` 组件区分，授权撤销后立即替换受限内容。技术绑定（驻留名额、writer、参与者、激活）移入“运行管理”。额度面板把准入上限与已预留、已结算、未知用量分开，按主机类别（业务决策、导演裁决、结果收尾、普通沟通、压缩、未归类）与 token 类型细分，不估算费用，并把主机级模型上限标为所有运行共享。恢复对话框首层说明恢复到的时间、恢复后保持暂停、不回滚历史、不重复已完成的模型调用以及检查点完整性；覆盖范围与技术标识作为后续展开层。

## 日志记录与导出

记录模块通过 runtime 持有独立的元数据窗口及精确原始记录检查页。已提交类型筛选和来源序号可通过 URL 重载／历史恢复，冻结上下文的 run-event 引用可打开精确记录。原始 JSON 仅在 Host 独立历史正文授权后作为文本显示。普通读取失败保留分页；策略撤销清正文并取消旧响应。日志顺序不被表示为真实或模拟时间。

显式导出从首页读取同一 revision／策略下所有匹配记录，生成文件前再次执行已认证读取。元数据与原文分别提供导出控件，原文须有整运行 `recordReaders` 授权。不完整、乱序、重复、过期、撤权或中断的导出不生成文件。`maxExportBytes` 默认限制完整 UTF-8 文件为 16777216 字节，`maxExportPages` 默认 2048 个数据页，另加一次最终复核请求；文件记录选择、revision 和策略版本。取消、切换视图／运行、断线及卸载均中止请求并清除文本缓冲。已完成下载的文件由用户持有，不会因后来撤权而自动删除。

## 查看与创建

目录保留有界名称窗口，只为这些准确且有序的 ID 读取一个运行状态批次。状态刷新与真实时间轮询不扫描全部原生运行。行区分不可用／缺失观察和零，保留准确 tick 字符串，并展示已观察的调度、在途工作、驻留确认与场景／规则／策略版本。读取失败保留标明过期的状态，换页或授权退役旧响应。导入场景身份未知时明确不可用，不从名称猜测。

命令面板提供“打开仿真”及已加载目录页中的运行。选择运行会写入与目录行相同的深链，因此后退和重新加载都能恢复；面板不会读取其他目录页。

每个运行模块保留同一个页头：身份行（返回、运行名称、World 的模拟世界标记、最近一次刷新结果、刷新）随页面滚走，其下是粘性命令带，包含运行状态标签、停止目标标签、运行详情、调度控制、维护溢出入口、一行状态说明和模块导航。身份行离开页面滚动容器后，命令带转为不透明并重复显示运行名称；该状态由 `IntersectionObserver` 在每次越界时切换一次。运行详情列出每个来源各自的修订号与观测时间（世界记录、调度控制、调度器观测），以及 owner、phase、调度器、已受理工作、连接、停止原因、故障标识和版本。切换模块不替换启动确认或原命令 owner；待处理操作保留标签，迟到的结果不会刷新另一个已选运行。运行详情和维护／输入溢出入口是锚定的 `<details>` 弹层，在外部按下或按 Escape 时关闭；维护条目仍是按钮并附带拒绝原因，打开既有保留表单。内容宽度小于 768px 时页头压缩为两行（身份行；状态与唯一主操作），模块改用菜单，表格变为带标签的卡片行；小于 540px 时命令带不再粘性，弹层改为底部面板。概览展示原生区间额度和额度面板；Host 模型准入另按真实时间统计正在处理与排队请求。Token 预算占用明确不等于已知实际模型用量，旧 peer 缺失的指标显示不可用。

Simulation 使用一个页面内容滚动容器。页头、模块内容和保留原操作保持自然高度，窄屏状态页头不能把输入／审核区域压成无法点击的零高度面板。View store 按目录或集合上下文记忆页面滚动；原生对话框保留各自有界表单滚动。

目录搜索明确提交登记名称查询，清除立即生效，并使用有界续页。集合状态和实体认知模式筛选使用有界 Host 查询；已提交筛选、关联实体／决策身份及操作分区在 URL 重载和浏览器历史中恢复。改变筛选回到首页，不复制全集。概览、实体、决策、操作和检查点通过非模态检查器提供精确对象元数据。检查器是停靠栏：集合沿用页面滚动，停靠栏粘在运行命令带下方（命令带发布的 `--run-band-block`）并自行滚动。内容宽度小于 880px 时，停靠栏以抬升表面覆盖在集合同一单元上，小于 540px 时占满宽度；集合在下方保持原位，返回入口关闭停靠栏。模拟时间保持精确十进制字符串。登记所有权、保存 phase、driver 进展、提案接受、效果执行、发布及消费保持独立。原生 revision 自动触发可见模块窗口重读；调度生命周期变化也会更新运行计数及任务／请求摘要。行政控制拒绝不撤销独立获准的查看元数据。实体与决策详情可跳转关联元数据。操作详情分别展示效果结果、依赖、发布时间及接收回执；发布尝试和检查点来源各有独立首页／续页控件。读取失败保留内容，刷新前禁用续页。来源引用仅为元数据。实体关系保留历史区间及明确端点跳转。决策上下文分区展示冻结来源，并独立分页原始分区片段／引用。Host 正文权限决定纯文本预览或明确删节；非文本 payload 保持未公开。该局部视图不称为完整模型请求。切换运行取消查看检查器与恢复来源读取。

创建只选择已安装的带版本模板及允许的名称／库存输入。Host 目录配置列出可编辑的实体／驻留／token／tick 额度及模板默认值／上限；留空沿用默认值。Host 共享模型并发上限只读，模拟时间单位、预算区间及规则／策略版本持续可见。检查配置调用无副作用预检，不分配命令身份。创建先重新预检未改变的草稿，再分配原命令；编辑、关闭、断线或授权替换退休进行中的校验。字段错误保留输入、关联对应控件并聚焦首个错误。原创建结果未知时，重试保留原额度，不将后来改写的草稿预检为替代操作。正数量保持十进制字符串，包括超过 JavaScript 安全整数范围的值。表单使用应用内验证、字段错误及 IME 安全提交。创建准备暂停运行及初始完整检查点，不推理。响应丢失保留原命令与 payload；查询或明确重试恢复该操作，不分配另一套运行。后来编辑的输入与已提交原请求保持独立。

## 调度与原结果

结果未知的外部工作在概览提供独立有界预览及准确操作链接。操作表单等待当前 Host 重试允许性与保留的尝试次数。授权只为原意图登记 Native 受限额度，不发布、不恢复调度，也不请求模型。查询及未解决原命令的重试保留规范化输入，不依赖新请求容量；已确认的日志终态与冲突终态仅允许查询。后来原始原因编辑不因回执丢失。明确拒绝后，另建命令须修改原因或明确确认当前尝试次数。私有操作草稿与输入／审核共享条目数及完整 UTF-8 额度，导航／断线保留，授权替换清理。授权完成后仍须明确调度才对账目标。

检查点／恢复回执及保留检查点详情只展示结构化阶段／类别／准确对象诊断。Team、频道和 Session 链接携带完整准确归属；运行／实体／检查点定位留在授权 Simulation 元数据内。清理未确认时独立说明。私有 provider 消息、存储路径与错误字符串解析不进入诊断 UI。已知失败诊断回执仍可查询原结果，不受新维护准入是否可用影响。

管理任务审核在概览中提供一个有界、固定观察版本的页面。行仅展示场景核验后的库存转移与报告发布 ID、准确数量、尝试／审核实体元数据及 Host 允许性提示；任务说明和原报告正文仍保持私有。通过与返工绑定原操作、尝试和任务版本。版本变化时须明确确认同一尝试的当前版本，不能用其他尝试替换保留目标。审核本身不启动推理。审核读取失败时保留已读行与警告，直到审核者手动刷新；实时观测不会悄然替换它。

私有审核草稿按运行／操作／尝试隔离，与实体输入共用条目数和完整 UTF-8 字节额度。关闭、导航和普通断线保留原因及原命令选择；授权替换清理。未知结果只能查询或精确重试原操作。提交时规范化空白，并保留受额度限制的原始提交草稿；完成结果只清理与该原始草稿完全相同的输入，后来仅修改空白也保留。终态失败不能用相同原因、决定与版本另建命令，须改写语义或明确核对新版本。审核写权限拒绝保留作者原操作、草稿及独立查看；真实认证退役仍清理。历史命令重新打开原审核表单，不进入维护表单。

Host 提供开始／暂停允许性，以及模型、token 区间、驻留和主机共享并发额度。Host 的执行历史提示决定继续文案，开始／暂停准入决定动作强调。等待中的动作保持标签，迟到结果不刷新后来选中的运行。开始确认标明运行及这些额度；浏览器不能修改共享 permit 上限。后台控制刷新保留有效控件，每次写入仍重新检查原生准入。暂停区分保存意图与仍在收尾的已受理工作。

保留操作视图展示原命令身份及 receipt，为未解决操作提供明确原结果查询和精确重试。`not-found` 不代表失败。开始／暂停结果未知时阻止创建相同的新意图，仍允许不同的明确意图。已知终态 receipt 可释放，待处理或未知原操作不能释放。查询、读取或导航不继续推理。

任务取消使用独立有界概览和精确 revision／可空 attempt 表单。原始 reason 和原命令共享现有草稿额度，关闭、导航及断线后保留。未知结果只允许原查询／重试；新拒绝后须语义编辑或明确确认当前 fence 才能新提交。认证替换清理私有草稿。取消归属 Simulation 行政管理，保留既有世界效果。

## 检查点、恢复与实体输入

Host 行政提示决定明确检查点、恢复、准备及实体输入表单的允许性。检查点确认解释暂停／排空／actor 退休，失败保留上一个完整采集。恢复展示精确兼容检查点、真实发布时间、前缀／当前 revision 及独立分页的 Run／Team／Channel／Session 引用。读取引用不验证来源，也不获取 writer；明确 restore 验证保留历史／当前后缀，退休旧 writer，返回暂停 owner，不回滚或重放模型。

实体输入只选择一个 Host 批准目标与规范最早 tick，不广播或增加权限。原始正文／目标／时间在关闭、模块切换和普通重连中保留。结果未知保留同一原选择，后来编辑保持独立。回执分开展示分配时间、pending／claimed／consumed／cancelled 及关联决策。新操作被阻止时，专用保留输入／原操作入口仍可用。明确确认回执只清除未改变的提交字段，后来编辑保留。共享额度拒绝保留旧草稿，不发送操作。

每个集合模块保留表格，并通过保存在 `simulationDisplay` URL 参数中的表格/可视化切换增加一个可视化视图：实体显示为按类别聚类的星图，具备 agent 认知的实体带光晕，驻留状态取自写入者状态；决策显示为时间线，每个实体一条泳道，按精确的 `BigInt` 缩放仿真时间放置状态标记，同刻槽位堆叠，并显示现在游标；操作显示为效果流水线（待处理、已应用或已拒绝、已发布、输入已持久化、已回执），另有已阻塞与结果未知侧泳道，并常驻说明回执不代表业务接受；检查点显示为轨道并突出最近一次成功。每个视图只绘制已加载的页并注明已加载与总数；运行级关系、时间范围滚动、因果箭头与脉搏序列等待各自的产品读取。运行控制台的驱动器环只在观察到驱动器活跃时转动，驻留席位图显示占用、等待释放与空闲席位；实时观察到驱动器启动时播放点火时刻，实时观察到检查点完成时播放封存时刻。空白首页显示 Simulation 模式卡片；目录尚未读取时，卡片只读取一次第一页有界目录，从不继续翻页。运行目录以卡片展示运行，尚未创建世界的运行只显示一行说明，不再列出空事实。

明确的 World 预检变化拒绝提供“新建意图”操作：保留被拒绝原件，恢复可编辑输入，并在再次创建前要求重新预检。传输结果未知及普通 invalid/not-found 响应仍锁定原 payload，并先查询原件恢复。

## 世界场景工作区

保留场景模板为 `clocky.world/v0/*` 或 `clocky.world/v1/*` 的运行显示六个主模块——概览、事项、组织、制度、外部世界与历史（`records` 路由）——并把实体、决策、操作、检查点与请求历史收进一个“诊断”菜单；路由 ID 不变。其他运行保持原有模块行。场景无法观察时，工作区明确说明并保留引擎模块行，刷新即可重试。

**新建世界**打开选择器：已安装的 Host 模板、`.json`／`.yaml`／`.yml` 文件（点击或拖放，超过 `maxWorldDraftBytes` 时就地拒绝）或只含必填骨架的空白定义，并列出最多三份未完成草稿。选择后在 `simulationAuthor=<slot>` 打开整页作者台；URL 只含不透明槽 ID。作者台保存一个规范 JSON 模型以及最后一次源码原文与格式。表单表格支持单元格选择、Enter／双击编辑、Escape、Tab 与方向键移动、只列出草稿内已声明符号的引用选择器、复制／移动／删除行及 5 秒撤销条；撤销历史有界。源码视图只用 Host 解码器做语法解析：语法错误保留原文、冻结表单，并提供跳到对应行的入口。手写源码后的首次表单编辑会先确认再重新生成源码。表单无法编辑的字段保留在模型中并标为“只能在源码中编辑”。新空白定义采用 `clocky.world/v1`；v1 的全部分节可编辑，包括委员会、制度、知识、资源、外部世界及通道。复合对象使用 JSON 单元格，开放区间保留必需的 null 结束值。未完成的单元格文本在切换视图时保留；取消重新生成或容量拒绝会恢复父草稿。旧 `clocky.world/v0` 定义中不支持的分节继续只读并显示“已预留”。目录 `worldTemplates` 只来自明确公开的 `world.authoringTemplates`；私有保留运行及导出不会填入选择器。

检查始终是显式操作（按钮或 Ctrl/Cmd+Enter）。共享场景编译器在本地报告结构错误，只有解析成功的定义才发往 Host 预检。诊断给出分节、可读路径、原始路径与行列；定位会聚焦负责的单元格或源码 token，F8／Shift+F8 在诊断间跳转。已修改的值使对应诊断显示删除线，直到下次检查；检查失败时保留上次结果并标为陈旧。编辑会使冻结预览（角色与模型路由、调控者权限、岗位、外部来源、标明默认／覆盖来源的额度、指纹）变暗，并禁用 **创建暂停运行**。创建前确认运行名、模型路由与额度，保留一个 `world-create` 原命令并锁定草稿；结果未知时仍先查询原件。导出下载 `<名称>.world.json|yaml`；运行概览以同样方式导出保留的定义。两个导出菜单都明确说明：原始场景定义用于创建新世界，不含运行进度、会话、凭证或宿主路径，不是运行备份。创作时写入的私有事实保留在可移植定义中，不会附加执行身份或私有运行记录。

World 预览和外部世界模块工具条在折叠分组之外完整显示不可关闭的仅模拟说明。每个 World 运行页头带有可聚焦的模拟世界标记，其 tooltip 与无障碍文本包含同一说明，因此引擎导航和页面重开后仍可获得；未发布的领域窗口仍明确显示未发布。

概览、组织（带占用与局部关系图的结构树、任职泳道、带义务与 Host 操作提示的人员）、制度（带票况与冻结 electorate 的提案、带时间事实的现行制度、版本历史与正文差异）及外部世界（身份、已知与未知事实、代表就绪状态、交互）渲染世界领域投影。事项表增加领域、操作、业务事项键、四条独立状态轨道以及补证／来源分区。每个列表都说明已加载与总数、修订号和查看时点，Host 范围键放在提示中。结构树每一层先列单元再列岗位，没有归属关系的岗位留在根层；组织与制度接受显式十进制 `simulationAt`，查看历史时点时禁用管理。管理面板保留草稿，但提交要求已安装的 Host 预览与命令 owner。引擎引用带历史记录地打开精确对象；悬停 400ms 只预览引用自身的类型、标识与名称，键盘用户通过描述获得相同文本。Host 报告新修订时，自动刷新可见领域窗口和所选详情。在途读取完成后合并执行一次最新读取，保留筛选、对象选择、滚动位置和编辑草稿。绑定修订的分页回到首页，日志原文仍保留所选分段。未变化的观测心跳不会触发读取。后台读取保留已有内容和空状态，不播放刷新按钮动画、不使内容变暗，也不插入过期提示。首次加载与真实失败仍有反馈；过期数据仍阻止绑定修订的续页和写操作。观测事实实时变化的行显示一次左侧强调标记并有节制地播报汇总；首次加载与刷新不标记。World 模块共用 `WorkspaceStage` 与 `InspectorDock`：停靠栏的标题、操作和分区标签固定，正文自行滚动。停靠栏从其边缘进入，正文晚一个错峰步长；切换分区时正文按切换方向缓入；关闭时停靠栏先向边缘淡出再提交关闭，选择其他对象会取消这次待提交的关闭。减少动效下只保留淡入淡出并立即关闭。内容宽度至少 1440px 时，检查器可拖拽或用方向键在 360px 与 `inspectorMaxWidth` 之间调整，宽度记忆在视图 store 中。投票与生效只供观察。L3 动效只在实时转换时播放：制度生效用 seal，代表就绪用 converge，新出现的退休未确认用 stall。

世界概览以仪表开场：模拟时间是页面最大的数字，旁边是修订号和最多五个已排定事件的有限时间轴，轴起点为本页首次观察到的时间。实时观测到时间前进时数字滚动、“现在”标记沿轴弹性移动，背景场回应一圈；两次观测之间不动。随后是一行“需要你处理”。制度、组织与外部世界三张卡片带 2px 领域色边（`--clocky-domain-*`），只表示所属领域、不表示状态：现行与已可知制度及前两个提案；在职与非终止人物、按上限绘制的驻留席位（超出上限以错误样式绘制）及带定义的历史计数；外部身份数及按本卡最大值缩放的来源类型条。事项流是一条按请求状态分段、宽度按计数、可点击的胶囊，零计数状态列在其后。“本页观察到的变化”只列出概览挂载期间实时看到的变化——运行的第一次投影是基线，刷新后清空，持久历史在“记录”。Host 标题为不透明标识的提案显示为“委员会 提案 · 短 ID”，完整标题保留在提示中。冻结 electorate 另以席位弧呈现，座位形状编码票型，等价列表并列保留。人员表中本页已加载值完全相同的列折叠为一条“本页”摘要。外部交互摘要与任职关系标识保持原文，单行截断并在 title 中给出全文；来源引用显示为紧凑芯片。

维护确认先说明作用对象（检查点标识为可复制芯片，并给出模拟时间、发布时间与检查点 → 当前版本），再以两列列表说明会发生与不会发生的事，最后给出待验证来源的计数，标识收在展开项中；执行按钮为主按钮。工作区把当前运行发布给背景场（`useAmbientScene`）：运行 ID 选择地形，只有观测到驱动正在工作时色调为全色；实时观测到驱动启动也会发出一圈。两个页头都提供在本浏览器暂停背景动效的开关。空目录渲染为一个舞台：装饰性星座、带就绪状态的已安装模板与创建操作；运行卡片在所写阶段旁带一段该阶段状态色的短边。

事项与其他世界模块共用舞台与检查器坞：每行先显示领域标签、操作与版本，下方为紧凑请求 ID，随后是申请者 → 目标，以及四条轨道并在旁写明请求状态；本页已加载行的业务事项键全部被隐藏时，该列折叠为一条“本页”摘要。打开检查器时路线与更新时间两列让位，检查器内给出请求 ID、路线、轨道与以标签页呈现的分区。内容较宽时，世界表格的表头在页面滚动时固定在运行命令带下方；命令带本身贴住滚动容器顶部，使用半透明表面并在下方渐隐，检查器与结构关系图固定在其正下方。引擎集合保留自身的行滚动区，表头固定，状态以保留原文的着色标记显示，ID 为等宽芯片；内容宽度小于 540px 时改为带字段标签的卡片，并改由页面滚动。引擎检查器使用图标关闭按钮、紧凑的身份标题（不透明 ID 用等宽字体）、分段式分区切换与两列事实网格。结构视角在未选中行时先显示根单元的邻域，“人员与录用邀约”是可展开面板，任职时线为无归属单元的人员标注分组并让边缘标签留在泳道内，制度历史使用同一时间刻度并标出查看时点。作者台在内容宽度不小于 1100px 时保持纵向分节栏，长表格滚动时固定各节标题，并把草稿保留说明、按 ID 重新打开与丢弃合并到同一页脚栏。

为降低阅读负担，作用于整页或整张卡片的说明（人员统计范围、事项流含义、本页变化的范围、仪表的观测规则、制度仅可观察、记录排序）放在标题旁的“i”提示中，提示文字作为其无障碍描述。概览只在窗口不完整或已过期时说明覆盖范围。未来日历编辑、预算与模型池、执行模式说明和请求记录集中在默认折叠的“运行管理”中，展开时各卡片依次缓入。目录卡片优先展示 phase 与模拟时间，场景版本与已受理工作放在卡片详情中。外部世界模块的模拟声明保持常驻可见。

创作工作台支持显式保存私有 v1 草稿，并通过已保存草稿 ID 重新打开。保存冲突显示双方定义；载入已保存版本或保留本地编辑均须明确选择。保存结果未知时保留原 ID 与 payload，后续本地编辑独立保留。组织图每个窗口最多显示 80 个匹配对象，并标明已保存版本与模拟时刻 0。将节点拖到上级对象，或使用等价列表控件，会暂存类型化命令，必须通过 Host 预检才更新共享草稿。表单、图与 JSON/YAML 使用同一定义；undo/redo 仅影响草稿。提交创建后锁定编辑。已有运行仍使用独立审核的管理命令。


每次 UI 生命周期捕获原 Simulation runtime；退休只关闭该生命周期的读者，不改变所选运行的 URL。退休后的 React 清理不再执行，不能暂停后继视图。

## Model Experience

### 明确 Simulation 调度

#### What the model sees

浏览、创建和原结果查询不贡献模型输入。明确开始调用已部署场景 driver，经所选 Simulation preset 使用已记录授权上下文。[公司 preset](../../../examples/simulation-company/presets/simulation/agent.cordis.yml)提供完整 Simulation persona 和`simulation_observe`、`simulation_stage` 和 `simulation_submit` 三种原生工具；这些请求不公开普通 Team 工具。

#### Token effect

查看、创建和结果查询没有直接影响。明确调度消耗配置的原生模型 permit 和运行预算；暂停阻止后续准入，已受理请求可能继续完成。

#### KV Cache effect

作用域 persona 和工具定义在 actor 生命周期内稳定。上下文与工具结果经其现有 Session 历史追加。

## Known Limitations and Deferred Work

- 停止保存说明不会收集完整外部案例备份；`external-state-required` 仍需提供方拥有的备份操作。显式重试使用新的物理检查点，但保留原逻辑停止命令与 cut。
- 新建世界的部署适配显示已声明的检查点备份覆盖、停止时钟与已公开的模型上下文窗口。初始上下文大小与长期用量明确显示为未知，也不报告提供方模型版本，因为没有主机读取能在不运行 World 的情况下估算它们。
- 概览业务卡使用第一页事项中最新的已授权投影摘要；目前尚无运行级业务投影读取。
- 领域窗口只覆盖所声明的有界范围；仅 Native 的义务窗口不完整，缺少驻留证据时显示未知。任意历史组织／人员／外部生命周期视图不可用。管理字段／预览在其 Host owner 安装前保持未发布，提交保持禁用。
- 已预留的作者分节在安装的世界编译器接受之前保持只读；源码视图使用原生 textarea，没有语法高亮。
- 新增自动任务场景、完整失败／中断矩阵仍有独立验收要求。
- 来源检查页显示受支持原文，任意 provider payload 保持删节。实体当前知识和决策已选精确版本使用独立页面，上下文引用可打开精确知识选择。当前受众撤销通过世界失效清除这些正文，只有独立 Host 来源权限允许时才显示原报告文本。元数据跳转和来源引用不授予 Team／Session 正文权限。
- 完整语言／主题／缩放／键盘、grant 收回及中断矩阵仍需验收。真实 JSON／SQLite 浏览器创建、控制、响应丢失和凭据替换覆盖声明流程；外部模型使用脚本，不代表真实 provider 或跨 Host 测试。

原生 revision 变化后，案件列表及所选分区自动重读。隐藏工作区停止自动读取。关闭直接链接或刷新后的案件时，键盘焦点回到精确的当前可见原申请行。World 导入和案件分区支持键盘导航、浅深主题、窄屏和减少动效。

World 人员卡片从现有认证 run inspection 的 `world.people` 读取，与分页领域窗口独立。六项计数分别显示当前任职、非终止 Person、resident 准入、未释放 writer，以及历史 Participant／Activation。缺少完整规范 Team 来源时，历史计数保持不可用。刷新只读；错误和普通断线保留标记过期的计数，认证替换则清除旧值。

Native `worldInitialized` metadata 使冷只读注册在没有管理 owner 时也能启用 World 导航。保留的 World 模板还可识别准备中的世界；领域读取等待初始 checkpoint 就绪。Native 与场景身份均缺失时保留引擎视图。

创作冲突显示有界字段差异、共同父版本和已保存作者，并保留双方完整原件。私人图窗口报告节点/关系覆盖范围与投影时点。坐标控件将布局与世界定义分别保存，不发出业务命令。模板包导出要求当前有效预检与明确许可证信息；导入依赖在创建前重新核对。解除依赖锁定是明确的新模板操作。布局和模板元数据均计入草稿字节额度。
