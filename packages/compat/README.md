# Compatibility packages

English | [中文](README.zh.md)

Private packages for explicit example compositions. Package names use `@clocky/clocky-compat-*`; model tools and the Goal command use `legacy_*` names. Product bundles, runtime carriers and public catalogs exclude them.

Family maps: [Goal](../goal/README.md), [subagent](../subagent/README.md), [script workflow](../workflow/README.md).
