## Known Limitations and Deferred Work

- Runs have one local coordinator; distributed execution and branch identity remapping remain unimplemented.

Belief/inference confidence is optional policy metadata in `[0, 1]`; it does not change visibility or world authority. Summaries retain exact premise versions and a policy generation, so current source revocation also blocks later summary retrieval. A future-dated revision does not hide an older version that is still available at the query time.

Compacted report references can be rematerialized without changing decision identity, snapshot or source versions. Presentations retain their required-section budget and prior hashes; Session repair accepts only an authoritative current/prior presentation. Oversized required material must be cancelled and re-prepared with an appropriate budget. A root reservation or completed checkpoint fixes the canonical execution Team even before any entity is bound. Binding, root reservation, checkpoint publication and attachment must agree with that retained identity; an unconfirmed root cannot be published as a complete checkpoint.

`external.interact/v3` declares director-mediated environmental facts, finite delayed leaves, typed failure, unverified quotations and finite representative preparation. The World definition freezes complete adjudication policy parameters; missing policy rejects installation of this operation. Conditions use closed schemas, and asset or commitment claims retain their original Native evidence. Authoritative facts use `clocky.world-fact/external-adjudicated/1` with typed claims, as-of time and slim original adjudication/event references. Unverified quotations remain reports. The Native owner supplies actual cognition versions and source references; model output cannot assign them. A committed representative plan appends its original requester first-contact wake and director result notification with ready state and representation in one bounded batch.

Requests retain permitted contact, inventory and quotation dimensions before adjudication. Native binds literal output units to those original dimensions. Low-reader results use fixed report/failure templates, opaque event identities and only original requester-declared evidence; raw director narrative and full evidence remain in the original adjudication body.

Scenario-directed environment requests require an original finite calendar and an explicitly opted-in domain. Each actual occurrence records an eligible director wake or an exhausted independent `maxRequests` budget. Native derives the trigger, stable business key, scope and target from that source; copied IDs, role text and arbitrary wakes cannot confer authority. Accepted cases retain the actual Director Decision/binding/epoch and trigger with `notificationOperationId: null`. Their request, plan and result observations consume separate causal Native contexts through the same Agent tools and shared fair queue. They create no self-directed Channel/Envelope. Ordinary requests retain their real private notification and consumed recipient proof. Rejected or cancelled scene cases remain charged; one occurrence admits one business identity. Delayed environment follow-ups consume their original recorded leaf and result wake. Native stream 102 rejects earlier formats; compiler 9 records the independent scene budgets and declared installed capabilities.

`resource/reserve` retains the authenticated actor, complete conserved transaction, one-use grant IDs and finite simulated `expiresAt`. Commit/cancel require its original ID/revision. Available amount excludes active debit holds; grant reuse, stale reads and commitment at the exact expiry time reject.
